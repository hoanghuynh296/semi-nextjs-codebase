# Avatar & LetterAvatar

A person or team: their image, two initials on a stable tone (`Avatar`), or one upper-cased letter (`vi` locale, "?" when empty) on a neutral fill (`LetterAvatar`, or `Avatar initials={1}`).

## When to use

- Owners, assignees, customers in rows and cards (`Avatar`).
- Neutral one-letter account or sender marks without a photo (`LetterAvatar`, used by the route header's account menu).

## Import

```tsx
import { Avatar, LetterAvatar } from "@semi/ui";
```

## Examples

### Sizes

```tsx
import { Avatar } from "@semi/ui";

export default function AvatarSizes() {
  return (
    <div className="flex items-center gap-3">
      <Avatar name="Hoàng Huỳnh" size="lg" />
      <Avatar name="Semi Team" />
      <Avatar name="Lan" size="sm" />
    </div>
  );
}
```

### One-letter neutral avatar

LetterAvatar draws the first letter upper-cased with the vi locale (Đ, Á, or ? when empty) on a neutral fill.

```tsx
import { LetterAvatar } from "@semi/ui";

export default function AvatarLetter() {
  return (
    <div className="flex items-center gap-3">
      <LetterAvatar name="Đặng Minh Anh" size="lg" />
      <LetterAvatar name="Hoàng Huỳnh" />
      <LetterAvatar name="ánh dương" size="sm" />
      <LetterAvatar name="" size="sm" />
    </div>
  );
}
```

## API

### Avatar

Person or team mark: photo, else initials on a tone picked from the name (stable per name).

| Prop | Type | Default | Description |
|---|---|---|---|
| `name` * | `string` |  |  |
| `src` | `string` |  |  |
| `size` | `'sm' \| 'md' \| 'lg'` | `"md"` |  |
| `initials` | `1 \| 2` | `2` | Number of initials to draw: `2` (default) uses the last two words; `1` uses the first letter (`vi` locale, "?" when empty). |
| `tone` | `'auto' \| 'neutral'` | `"auto"` | `auto` picks a stable category tone from the name; `neutral` uses the neutral raised fill (as in LetterAvatar). |
| `className` | `string` |  |  |

### LetterAvatar

One-letter neutral avatar: the name's first letter upper-cased with the `vi` locale ("?" when empty) on a neutral fill; accessible name = the full name.

| Prop | Type | Default | Description |
|---|---|---|---|

| `size` | `'sm' \| 'md' \| 'lg'` | `"md"` |  |

## Accessibility

- The full name is the accessible label (`role="img"` + `aria-label`); mark `aria-hidden` when placed next to the same visible name.
