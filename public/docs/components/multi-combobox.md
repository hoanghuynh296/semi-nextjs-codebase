# Multi combobox

Searchable multi-select: chosen values show as removable chips, an add button (default “Thêm” / “Add”) opens a portaled popover with a quiet search field and a checkbox list. Supports option groups (`group`), diacritic-aware search and Vietnamese Telex IME.

## When to use

- Picking several values from a long or grouped list in a form (supplied goods, tags, assignees, repositories).

## Use something else when

| Need | Use |
|---|---|
| Pick one value with search | CustomCombobox |
| Pick one value from a short fixed list | CustomSelect |
| Filter a list page in a toolbar | FilterChipRow |

## Import

```tsx
import { MultiCombobox, type MultiComboboxOption } from "@semi/ui";
```

## Examples

### Chips and searchable popover

```tsx
"use client";

import { useState } from "react";
import { Field, MultiCombobox } from "@semi/ui";

const GOODS = [
  { value: "tieu-den", label: "Hạt tiêu đen Đắk Lắk" },
  { value: "que-yen-bai", label: "Quế thanh Yên Bái" },
  { value: "hoa-hoi", label: "Hoa hồi Lạng Sơn" },
  { value: "ca-phe-robusta", label: "Cà phê Robusta Gia Lai" },
  { value: "dieu-binh-phuoc", label: "Hạt điều Bình Phước" },
];

export default function MultiComboboxBasic() {
  const [selected, setSelected] = useState<string[]>(["tieu-den", "que-yen-bai"]);
  return (
    <div className="max-w-lg">
      <Field label="Mặt hàng cung ứng">
        <MultiCombobox label="Mặt hàng cung ứng" value={selected} onChange={setSelected} options={GOODS} />
      </Field>
    </div>
  );
}
```

### Grouped options

Consecutive options with the same group share a heading; headings stay only while at least one option matches and are skipped by arrow keys.

```tsx
"use client";

import { useState } from "react";
import { Field, MultiCombobox, type MultiComboboxOption } from "@semi/ui";

const OPTIONS: MultiComboboxOption[] = [
  { value: "tieu-den", label: "Hạt tiêu đen", group: "Gia vị Tây Nguyên" },
  { value: "tieu-trang", label: "Hạt tiêu trắng", group: "Gia vị Tây Nguyên" },
  { value: "que-yen-bai", label: "Quế thanh Yên Bái", group: "Gia vị miền Bắc" },
  { value: "hoa-hoi", label: "Hoa hồi Lạng Sơn", group: "Gia vị miền Bắc" },
  { value: "ca-phe", label: "Cà phê Robusta", group: "Nông sản khác" },
];

export default function MultiComboboxGroups() {
  const [selected, setSelected] = useState<string[]>(["tieu-den"]);
  return (
    <div className="max-w-lg">
      <Field label="Danh mục sản phẩm">
        <MultiCombobox label="Danh mục sản phẩm" value={selected} onChange={setSelected} options={OPTIONS} />
      </Field>
    </div>
  );
}
```

## API

## Accessibility

- Each removable chip has a remove button with an accessible name (“Bỏ chọn <label>” / “Remove <label>”).
- Inside the popover: the search input is a combobox owning a multi-select listbox (↑/↓ skip group headings, Enter / Space toggle, Escape closes and returns focus to the add button; IME composition keys are ignored).
