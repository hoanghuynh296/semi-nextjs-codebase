# Empty state

What an empty list or page shows: an icon, one short title, a description and the action that fills it.

## When to use

- No items yet, no search results, a feature not set up.

## Import

```tsx
import { EmptyState } from "@semi/ui";
```

## Examples

### First item

```tsx
import { Button, EmptyState } from "@semi/ui";

export default function EmptyStateBasic() {
  return (
    <EmptyState
      icon="printer"
      title="Chưa có máy in nào"
      description="Thêm máy in đầu tiên để theo dõi tiến độ và nhiệt độ."
      action={
        <Button variant="primary" icon="plus">
          Thêm máy in
        </Button>
      }
    />
  );
}
```

## API

### EmptyState

Empty list / first-run state: icon, one short line, optional description and action (EMPTY surface).

- The title is a heading; the action is a normal button.
