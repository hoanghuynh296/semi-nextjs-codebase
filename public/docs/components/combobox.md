# Combobox

CustomCombobox: type to filter a long or grouped list (diacritic-aware, IME-safe), then pick one value or keep a new one.

## When to use

- Long or grouped lists the user searches (materials, customers, repositories, SKUs).

## Use something else when

| Need | Use |
|---|---|
| A short fixed list without search | CustomSelect |
| Pick multiple values with removable chips | MultiCombobox |

## Import

```tsx
import { CustomCombobox, type CustomComboboxOption } from "@semi/ui";
```

## Examples

### Searchable list

```tsx
"use client";

import { useState } from "react";
import { CustomCombobox, Field } from "@semi/ui";

export default function ComboboxBasic() {
  const [material, setMaterial] = useState("pla_matte");
  return (
    <Field label="Vật liệu">
      <CustomCombobox
        value={material}
        onChange={setMaterial}
        placeholder="Tìm loại nhựa…"
        options={[
          { value: "pla_matte", label: "eSUN PLA Matte Black" },
          { value: "petg_hf", label: "Bambu PETG-HF White" },
          { value: "abs_fire", label: "Polymaker ABS Fire Red" },
          { value: "tpu_95a", label: "Inland TPU 95A Orange" },
        ]}
      />
    </Field>
  );
}
```

### Grouped options

Pass group on consecutive options; headings stay only while one of their options matches.

```tsx
"use client";

import { useState } from "react";
import { CustomCombobox, Field, type CustomComboboxOption } from "@semi/ui";

const REPOS: CustomComboboxOption[] = [
  { value: "semi-nextjs-codebase", label: "semi-nextjs-codebase", group: "Nền tảng" },
  { value: "semi-brand", label: "semi-brand", group: "Nền tảng" },
  { value: "sales-hub", label: "sales-hub", group: "Ứng dụng" },
  { value: "data-hub", label: "data-hub", group: "Ứng dụng" },
  { value: "feedback-hub", label: "feedback-hub", group: "Ứng dụng" },
];

export default function ComboboxGroups() {
  const [repo, setRepo] = useState("");
  return (
    <div className="max-w-md">
      <Field label="Kho mã nguồn">
        <CustomCombobox value={repo} onChange={setRepo} placeholder="Tìm repo…" options={REPOS} />
      </Field>
    </div>
  );
}
```

## Accessibility

- ARIA combobox: arrows move through matching enabled options (skipping group headings), Enter picks, Escape closes; works inside Field.
- Option groups use role="group" + aria-labelledby so headings are announced and not selectable; a heading disappears when none of its options match.
