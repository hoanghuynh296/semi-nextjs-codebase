# Combobox

CustomCombobox: type to filter a long list, then pick one value.

## When to use

- Long lists the user searches (materials, customers, SKUs).

## Use something else when

| Need | Use |
|---|---|
| A short fixed list | CustomSelect |

## Import

```tsx
import { CustomCombobox } from "@semi/ui";
```

## Examples

### Searchable list

```tsx
"use client";

import { useState } from "react";
import { CustomCombobox, Field } from "@semi/ui";

export default function ComboboxBasic() {
  const [material, setMaterial] = useState("pla_matte");
  return (
    <Field label="Vật liệu">
      <CustomCombobox
        value={material}
        onChange={setMaterial}
        placeholder="Tìm loại nhựa…"
        options={[
          { value: "pla_matte", label: "eSUN PLA Matte Black" },
          { value: "petg_hf", label: "Bambu PETG-HF White" },
          { value: "abs_fire", label: "Polymaker ABS Fire Red" },
          { value: "tpu_95a", label: "Inland TPU 95A Orange" },
        ]}
      />
    </Field>
  );
}
```
