# Option cards

Selectable cards with radio-group semantics (arrow keys, single tab stop): icon, name, optional description, neutral selected state (`bg-item-selected` + `border-outline-line` + `text-strong`, no brand tint) and 8px grid gap.

## When to use

- Picking one visual option from 2–6 choices (an AI provider, a shipping method, a plan) where a card with an icon or short description reads faster than a radio list.

## Use something else when

| Need | Use |
|---|---|
| Compact inline radio list without cards | RadioGroup |
| Pick one from a long or searchable list | CustomSelect or CustomCombobox |
| Pick multiple values with search and chips | MultiCombobox |

## Import

```tsx
import { OptionCards, type OptionCardItem } from "@semi/ui";
```

## Examples

### Provider picker

Overline section label above a 2-column grid of option cards.

```tsx
"use client";

import { useState } from "react";
import { OptionCards } from "@semi/ui";

export default function OptionCardsBasic() {
  const [provider, setProvider] = useState("openai");
  return (
    <div className="space-y-3 max-w-xl">
      <div className="text-overline text-muted">Nhà cung cấp AI</div>
      <OptionCards
        label="Nhà cung cấp AI"
        value={provider}
        onChange={setProvider}
        options={[
          { value: "openai", label: "OpenAI", icon: "sparkles" },
          { value: "anthropic", label: "Anthropic", icon: "cpu" },
          { value: "google", label: "Google Gemini", icon: "zap" },
          { value: "local", label: "Máy chủ nội bộ", icon: "server" },
        ]}
      />
    </div>
  );
}
```

### With descriptions

Each card can carry a short muted description.

```tsx
"use client";

import { useState } from "react";
import { Field, OptionCards } from "@semi/ui";

export default function OptionCardsDescriptions() {
  const [delivery, setDelivery] = useState("warehouse");
  return (
    <div className="max-w-xl">
      <Field label="Phương thức giao hàng">
        <OptionCards
          value={delivery}
          onChange={setDelivery}
          options={[
            { value: "warehouse", label: "Giao tại kho", description: "Nhận hàng trực tiếp tại kho Bình Dương.", icon: "truck" },
            { value: "port", label: "FOB cảng Hải Phòng", description: "Nhà cung cấp chịu chi phí đến khi hàng lên tàu.", icon: "globe" },
            { value: "express", label: "Chuyển phát nhanh", description: "Chỉ áp dụng cho mẫu dưới 5 kg.", icon: "zap" },
          ]}
        />
      </Field>
    </div>
  );
}
```

## API

### OptionCards

Selectable option cards with radio-group semantics: icon, name, optional description, 8px grid gap, neutral selected
fill (`bg-item-selected`, `border-outline-line`, `text-strong`, no brand tint). Arrow keys move selection and focus;
the group is one tab stop.

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` * | `T` |  |  |
| `onChange` * | `(value: T) => void` |  |  |
| `options` * | `OptionCardItem<T>[]` |  |  |
| `label` | `string` |  | Accessible name of the group when not inside a `Field` or named by `aria-labelledby`. |
| `columns` | `1 \| 2 \| 3 \| 4` | `2` | Column count from `sm` up (stacks to 1 column on phones for readability at 375px). |
| `disabled` | `boolean` | `false` |  |
| `className` | `string` |  |  |
| `aria-label` | `string` |  |  |
| `aria-labelledby` | `string` |  |  |

## Accessibility

- role="radiogroup" with role="radio" and aria-checked; roving tabindex gives the whole group one tab stop.
- Arrow keys (←/→/↑/↓) and Home/End move both selection and focus, wrapping around and skipping disabled cards.
