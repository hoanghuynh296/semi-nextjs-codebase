# Toggle

Buttons that stay pressed. Toggle for one (pin, mute, bold); ToggleGroup for a set of icon or short options, one or several at a time (list / grid view, text styles).

## When to use

- A view mode with icons; text formatting; a pin / follow / mute switch on a toolbar.

## Use something else when

| Need | Use |
|---|---|
| Filter a list by text options | Pills |
| A setting saved immediately with a label | Switch |

## Import

```tsx
import { Toggle, ToggleGroup } from "@semi/ui";
```

## Examples

### Toggle

```tsx
"use client";

import { useState } from "react";
import { Toggle } from "@semi/ui";

export default function ToggleBasic() {
  const [pinned, setPinned] = useState(false);
  return (
    <Toggle pressed={pinned} onPressedChange={setPinned} icon="pin">
      {pinned ? "Đã ghim" : "Ghim"}
    </Toggle>
  );
}
```

### View mode (single) and styles (multiple)

```tsx
"use client";

import { useState } from "react";
import { ToggleGroup } from "@semi/ui";

export default function ToggleGroupBasic() {
  const [view, setView] = useState<("grid" | "list")[]>(["grid"]);
  const [styles, setStyles] = useState<("bold" | "italic" | "code")[]>(["bold"]);
  return (
    <div className="flex flex-wrap gap-3">
      <ToggleGroup
        label="Chế độ xem"
        value={view}
        onChange={setView}
        options={[
          { key: "grid", icon: "grid", "aria-label": "Lưới" },
          { key: "list", icon: "menu", "aria-label": "Danh sách" },
        ]}
      />
      <ToggleGroup
        type="multiple"
        label="Kiểu chữ"
        value={styles}
        onChange={setStyles}
        options={[
          { key: "bold", label: "Đậm" },
          { key: "italic", label: "Nghiêng" },
          { key: "code", icon: "code", "aria-label": "Code" },
        ]}
      />
    </div>
  );
}
```

## API

### Toggle

One button that stays pressed (aria-pressed). Icon-only needs an aria-label.

| Prop | Type | Default | Description |
|---|---|---|---|
| `pressed` * | `boolean` |  |  |
| `onPressedChange` * | `(pressed: boolean) => void` |  |  |
| `icon` | `IconName` |  |  |
| `disabled` | `boolean` |  |  |
| `className` | `string` |  |  |
| `children` | `React.ReactNode` |  |  |
| `aria-label` | `string` |  |  |
| `title` | `string` |  |  |

### ToggleGroup

A set of toggles on one track. type="single" (default) behaves like a radio group (←/→ move and select);
type="multiple" is a toolbar of independent toggles. Value is a list of keys in both cases.

| Prop | Type | Default | Description |
|---|---|---|---|
| `options` * | `ToggleOption<T>[]` |  |  |
| `value` * | `T[]` |  |  |
| `onChange` * | `(value: T[]) => void` |  |  |
| `type` | `'single' \| 'multiple'` | `"single"` |  |
| `label` * | `string` |  | Accessible name of the group. |
| `className` | `string` |  |  |

## Accessibility

- Toggle uses aria-pressed. ToggleGroup type="single" is a radio group (←/→ move and select), type="multiple" a toolbar of pressed buttons. Icon-only options need aria-label.
