# Context meter

How full the model's context window is: a small ring with the percent, token counts in a tooltip; amber from 80%, red from 95%.

## When to use

- Next to the composer or model picker in long chats and agent sessions.

## Use something else when

| Need | Use |
|---|---|
| A quota or upload progress | Progress |

## Import

```tsx
import { ContextMeter } from "@semi/ui";
```

## Examples

### Levels

```tsx
import { ContextMeter } from "@semi/ui";

export default function ContextMeterLevels() {
  return (
    <div className="flex flex-wrap items-center gap-4">
      <ContextMeter used={12_400} total={200_000} />
      <ContextMeter used={168_000} total={200_000} />
      <ContextMeter used={196_500} total={200_000} />
    </div>
  );
}
```

## API

### ContextMeter

How much of the model's context window is used: a small ring and the percent (role="meter"), with the token counts
in a tooltip. Turns amber from 80% and red from 95%, when the app should summarise or start a new chat.

| Prop | Type | Default | Description |
|---|---|---|---|
| `used` * | `number` |  |  |
| `total` * | `number` |  |  |
| `label` | `string` |  |  |
| `showValue` | `boolean` | `true` |  |
| `className` | `string` |  |  |

## Accessibility

- role="meter" with aria-valuetext “12K / 200K token (6%)”; focusable so keyboard users get the tooltip; colour is backed by the percent.
