# Brand signature

The brand's own motif (BrandPattern) and its big number (BrandFigure): what makes a screen look like this brand and not like every other AI-made app.

## When to use

- A landing hero, a report cover, an empty state or an avatar placeholder needs the brand's look (BrandPattern).
- A section leads with one number: a landing proof point, a report total, a dashboard's main figure outside a card (BrandFigure).

## Use something else when

| Need | Use |
|---|---|
| A metric in a row of cards | KpiCard (featured for the main one) |
| Photos and illustrations | the brand's imagery rule in BRAND.md, not a pattern |
| Decoration behind tables, forms or body text | nothing: the motif is for open space only |

## Import

```tsx
import { BrandPattern, BrandFigure } from "@semi/ui";
```

## API

### BrandPattern

The brand's repeating motif (from its logo mark, dots, lines or a grid; brand.json "motif") as a decorative layer.
Put it first inside a `relative overflow-hidden` block: a hero, an empty state, a cover or avatar placeholder. Text
never sits on the motif itself: keep it on the calm half (`area="end"`) or on a panel above it. Never behind tables or
forms. Renders nothing visible when the brand chose no motif.

| Prop | Type | Default | Description |
|---|---|---|---|
| `tone` | `'accent' \| 'muted' \| 'on-accent'` | `"accent"` | Colour of the motif: accent (on a neutral surface), muted, or on-accent (on a bg-accent hero). |
| `area` | `'end' \| 'full'` | `"end"` | end = the end half only (text at the start stays on a calm background); full = the whole block. |
| `className` | `string` | `""` |  |

### BrandFigure

A big number set in the brand's figure font and title weight: the one figure a landing section, a report cover or
a dashboard leads with. For a metric among others in a card row use KpiCard (featured for the main one).

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` * | `React.ReactNode` |  |  |
| `label` * | `React.ReactNode` |  | What the number counts, in a few words. |
| `sub` | `React.ReactNode` |  | Optional context: period, comparison, source. |
| `size` | `'lg' \| 'xl'` | `"lg"` | lg = display size; xl = hero size (1.6 × display). |
| `onAccent` | `boolean` | `false` | On a bg-accent block (expressive hero): text-on-accent instead of the neutral text colours. |
| `className` | `string` | `""` |  |

## Accessibility

- BrandPattern is aria-hidden and ignores the pointer; text on top keeps its own contrast.
- BrandFigure is plain text: the label says what the number counts.
