# Text tabs

Large text tabs that are the page heading: 2–4 sibling views in display type, the current one bright and the others dim, no underline. Buttons switch at once; tabs with href are links, so the URL picks the view.

## When to use

- A page whose heading is a choice of 2–4 sibling views (Đang xử lý / Đã giao / Tất cả).
- Views people link to or reload into: give the tabs an href (URL-driven).

## Use something else when

| Need | Use |
|---|---|
| Sections of one record inside a page or card | Tabs |
| Filters of one list (status, owner) | Pills |
| A page with one title | PageTitle |

## Import

```tsx
import { TextTabs } from "@semi/ui";
```

## Examples

### Page heading with a panel

```tsx
"use client";

import { useState } from "react";
import { TextTabs } from "@semi/ui";

export default function TextTabsHeading() {
  const [view, setView] = useState<"open" | "done" | "all">("open");
  return (
    <TextTabs
      label="Đơn hàng"
      value={view}
      onChange={setView}
      items={[
        { key: "open", label: "Đang xử lý" },
        { key: "done", label: "Đã giao" },
        { key: "all", label: "Tất cả" },
      ]}
    >
      <p className="text-ui text-body">{view === "open" ? "12 đơn đang xử lý." : view === "done" ? "48 đơn đã giao tuần này." : "60 đơn."}</p>
    </TextTabs>
  );
}
```

### URL-driven

```tsx
"use client";

import { TextTabs } from "@semi/ui";

/** URL-driven: each tab is a link and the page reads the current one from the URL (here a fixed value). */
export default function TextTabsLinked() {
  const view = "suppliers"; // e.g. from useSearchParams().get("view") or the route
  return (
    <TextTabs
      label="Mua hàng"
      heading={false}
      value={view}
      items={[
        { key: "requests", label: "Yêu cầu", href: "?view=requests" },
        { key: "suppliers", label: "Nhà cung cấp", href: "?view=suppliers" },
      ]}
    />
  );
}
```

## API

### TextTabs

| Prop | Type | Default | Description |
|---|---|---|---|
| `items` * | `TextTabItem<T>[]` |  |  |
| `value` * | `T` |  | The current tab (read it from the URL for linked tabs). |
| `onChange` | `(key: T) => void` |  | Called with the tab chosen; tabs with `href` call it too, then navigate. |
| `label` * | `string` |  | Accessible name of the tab list ("Đơn hàng"). |
| `heading` | `boolean` | `true` | Wrap the tabs in the page's `h1` (default): they are the page heading. Set false when the page has its own h1. |
| `children` | `React.ReactNode` |  | The current tab's content, rendered in the tab panel. Omit to render the content yourself below. |
| `className` | `string` |  |  |
| `panelClassName` | `string` | `"pt-4"` |  |

## Accessibility

- WAI-ARIA tabs: tablist / tab / tabpanel, ←/→, Home, End move and the current tab is the only tab stop.
- Buttons switch as focus moves; linked tabs (href) move focus only and Enter follows the link, so arrows never load a route.
- The tabs sit in the page h1 by default (heading={false} when the page has its own h1); the panel is linked to its tab when children are given.

## Notes

- Dim tabs use text-muted (≥ 4.5:1 in both themes): never lighter.
- More than 4 views, or long names: Tabs or a CustomSelect, not TextTabs.
