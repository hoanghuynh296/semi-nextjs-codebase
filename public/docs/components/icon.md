# Icon

The semantic icon registry (stroke 1.75, 24px grid). IconTile is the rounded tinted square that leads cards and dialogs.

## When to use

- Every icon in the UI: pick the semantic name (trash = delete, close = dismiss, refresh = reload). See docs/ICONS.md.

## Use something else when

| Need | Use |
|---|---|
| A missing icon | add it to ICONS in @semi/ui (/semi-propose), never an inline <svg> |

## Import

```tsx
import { Icon, IconTile, ICONS, suggestIcon } from "@semi/ui";
```

## Examples

### Icons and tiles

```tsx
import { Icon, IconTile } from "@semi/ui";

export default function IconBasic() {
  return (
    <div className="flex flex-wrap items-center gap-4">
      <Icon name="printer" className="w-5 h-5 text-body" />
      <Icon name="trash" className="w-5 h-5 text-danger-fg" title="Xoá" />
      <Icon name="refresh" className="w-5 h-5 text-accent-fg" />
      <IconTile name="box" tone="green" />
      <IconTile name="camera" tone="sky" size="lg" />
    </div>
  );
}
```

### IconTile

Rounded square with an icon: the leading visual of cards, list rows and dialogs.

| Prop | Type | Default | Description |
|---|---|---|---|
| `name` * | `IconName` |  |  |

| `size` | `'sm' \| 'md' \| 'lg'` | `"md"` |  |

## Accessibility

- Decorative by default (aria-hidden); pass title when the icon alone carries meaning.
