# Page actions

Lets a page put its actions into a slot of the shared header: PageActionsProvider wraps the layout, PageActionsSlot marks where they render, PageActions sends them from the page.

## When to use

- A layout owns the header row but the page decides the actions (PageTabsTitle + “+”).

## Import

```tsx
import { PageActions, PageActionsProvider, PageActionsSlot } from "@semi/ui";
```

## Examples

### Actions in the header slot

```tsx
"use client";

import { useState } from "react";
import { Button, PageActions, PageActionsProvider, PageActionsSlot, PageTabsTitle } from "@semi/ui";

export default function PageActionsSlotExample() {
  const [view, setView] = useState<"printers" | "jobs">("printers");
  return (
    <PageActionsProvider>
      <div className="flex items-end gap-3">
        <PageTabsTitle
          value={view}
          onChange={setView}
          tabs={[
            { key: "printers", label: "Máy in" },
            { key: "jobs", label: "Job in" },
          ]}
        />
        <PageActionsSlot className="ml-auto" />
      </div>
      {/* Declared by the page content, shown in the slot above */}
      <PageActions>
        <Button variant="primary" iconOnly icon="plus" aria-label={view === "printers" ? "Thêm máy in" : "Tạo job"} />
      </PageActions>
    </PageActionsProvider>
  );
}
```

## API

### PageActions

### PageActionsSlot

## Accessibility

- Rendered through a portal into the slot, so tab order follows the header.
