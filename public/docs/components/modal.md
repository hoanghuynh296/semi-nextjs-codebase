# Modal

The shared dialog: full screen on phones, a centred panel from sm up, with title, description, body and footer. Focus is trapped and returns to the opener.

## When to use

- A short task that needs the user's full attention (edit settings, create an item).

## Use something else when

| Need | Use |
|---|---|
| Yes / no before a destructive action | confirmDialog() |
| Filters or details beside the page | Drawer |
| A short message after an action | toast() |

## Import

```tsx
import { Modal } from "@semi/ui";
```

## Examples

### Form in a modal

```tsx
"use client";

import { useState } from "react";
import { Button, Field, Input, Modal } from "@semi/ui";

export default function ModalBasic() {
  const [open, setOpen] = useState(false);
  return (
    <>
      <Button icon="sliders" onClick={() => setOpen(true)}>
        Cấu hình in
      </Button>
      <Modal
        open={open}
        onClose={() => setOpen(false)}
        title="Cấu hình in nâng cao"
        description="Áp dụng cho các bản in tiếp theo."
        footer={
          <>
            <Button size="modal" onClick={() => setOpen(false)}>
              Huỷ
            </Button>
            <Button size="modal" variant="primary" onClick={() => setOpen(false)}>
              Lưu
            </Button>
          </>
        }
      >
        <Field label="Tốc độ lớp đầu">
          <Input defaultValue="50 mm/s" />
        </Field>
        <Field label="Độ dày lớp">
          <Input defaultValue="0.20 mm" />
        </Field>
      </Modal>
    </>
  );
}
```

## API

### Modal

| Prop | Type | Default | Description |
|---|---|---|---|
| `open` * | `boolean` |  |  |
| `onClose` * | `() => void` |  |  |
| `title` * | `React.ReactNode` |  |  |
| `description` | `React.ReactNode` |  | Optional one-line description under the title (announced with the dialog). |
| `footer` | `React.ReactNode` |  | Action buttons rendered inside MODAL_FOOT (use MODAL_BTN_PRIMARY / MODAL_BTN_SECONDARY / MODAL_BTN_DANGER or <Button size="modal">). |
| `maxWidth` | `string` | `"max-w-lg"` | Width class on >= sm screens (e.g. "max-w-md", "max-w-lg", "max-w-2xl"). |
| `closeOnBackdrop` | `boolean` | `true` | Close when the backdrop is clicked (turn off for forms that would lose input). |
| `children` * | `React.ReactNode` |  |  |

## Accessibility

- role="dialog" + aria-modal, labelled by the title; Escape and the close button close it; focus trap and focus return built in; page scroll is locked.
