# Date picker

A date field with a Calendar popover (YYYY-MM-DD, min / max). Never type="date".

## When to use

- Schedule a job, filter by day, set a due date.

## Use something else when

| Need | Use |
|---|---|
| Pick on the page, or a range | Calendar |

## Import

```tsx
import { DatePicker } from "@semi/ui";
```

## Examples

### Basic

```tsx
"use client";

import { useState } from "react";
import { DatePicker } from "@semi/ui";

export default function DatePickerBasic() {
  const [date, setDate] = useState("2026-11-01");
  return <DatePicker value={date} onChange={setDate} min="2026-10-01" ariaLabel="Ngày in" />;
}
```

## Accessibility

- The button's name includes the chosen date; the popover is a dialog with the Calendar grid (arrows, PageUp / PageDown, Enter); Escape closes and returns focus to the button.
