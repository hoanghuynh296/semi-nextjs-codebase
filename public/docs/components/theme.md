# Theme

Light / dark / system: ThemeScript applies the stored theme before paint, ThemeProvider keeps it, ThemeSwitcher (three-way) and ThemeToggle switch it. data-theme on any element re-scopes every token inside it.

## When to use

- Once in every app's root layout; the switcher in settings or the sidebar footer.

## Import

```tsx
import { ThemeProvider, ThemeScript, ThemeSwitcher, ThemeToggle, useTheme, themeScript } from "@semi/ui";
```

## Examples

### Switchers

```tsx
"use client";

import { ThemeSwitcher, ThemeToggle, useTheme } from "@semi/ui";

export default function ThemeSwitchers() {
  const { theme, resolvedTheme } = useTheme();
  return (
    <div className="flex flex-wrap items-center gap-3">
      <ThemeSwitcher showLabels />
      <ThemeSwitcher />
      <ThemeToggle />
      <span className="text-label text-muted tabular-nums">
        theme = {theme} · resolved = {resolvedTheme}
      </span>
    </div>
  );
}
```

### Scoped theme

data-theme on a wrapper fixes the theme of everything inside it.

```tsx
import { Badge, Button, Card } from "@semi/ui";

export default function ThemeScope() {
  return (
    <div className="grid gap-3 @2xl:grid-cols-2">
      {(["light", "dark"] as const).map((t) => (
        <div key={t} data-theme={t} className="rounded-card border border-line bg-canvas p-3">
          <Card className="p-3 space-y-2">
            <div className="flex items-center justify-between">
              <span className="text-ui font-semibold text-contrast">data-theme="{t}"</span>
              <Badge tone="emerald" dot>
                Online
              </Badge>
            </div>
            <Button variant="primary" icon="check">
              Lưu
            </Button>
          </Card>
        </div>
      ))}
    </div>
  );
}
```

### Root layout

```tsx
import { ConfirmHost, TaskHost, ThemeProvider, ThemeScript, ToastHost } from "@semi/ui";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="vi" suppressHydrationWarning>
      <head>
        <ThemeScript />
      </head>
      <body className="bg-canvas text-body">
        <ThemeProvider>
          {children}
          <ToastHost />
          <ConfirmHost />
          <TaskHost />
        </ThemeProvider>
      </body>
    </html>
  );
}
```

## API

### ThemeProvider

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` * | `React.ReactNode` |  |  |
| `defaultTheme` | `'light' \| 'dark' \| 'system'` | `"dark"` |  |
| `storageKey` | `string` | `"semi-theme"` |  |
| `attribute` | `string` | `"data-theme"` |  |

### ThemeScript

Render inside <head> of the root layout, with the same options as ThemeProvider:
  <html lang="vi" suppressHydrationWarning><head><ThemeScript /></head><body><ThemeProvider>…

| Prop | Type | Default | Description |
|---|---|---|---|
| `defaultTheme` | `'light' \| 'dark' \| 'system'` |  |  |
| `storageKey` | `string` |  |  |
| `attribute` | `string` |  |  |

### ThemeSwitcher

Three-way theme picker (Sáng · Tối · Hệ thống) for settings pages and sidebar footers. ThemeToggle is the one-tap dark/light flip.

| Prop | Type | Default | Description |
|---|---|---|---|
| `showLabels` | `boolean` | `false` | Show the text label next to each icon (default: icons only, label in the tooltip). |
| `fullWidth` | `boolean` | `false` | Stretch to the container width (sidebar footers, settings rows). |
| `labels` | `Record<Theme, string>` |  | Override the labels (default: the SemiLocaleProvider strings). |
| `className` | `string` | `""` |  |

### ThemeToggle

Theme toggle button: seamlessly switches between Dark and Light mode.

| Prop | Type | Default | Description |
|---|---|---|---|
| `className` | `string` | `""` |  |
| `size` | `'sm' \| 'md'` | `"md"` |  |

## Accessibility

- ThemeSwitcher is a radio group; nothing is marked selected until the stored theme is known (no flash).
