# Chip

A pill-shaped toggle for filters and tags, without a border. Off: the subtle button fill; on: the raised surface (or its tone's tint) with a leading check, so the state does not rest on colour alone. 34px, 44px on a touch phone.

## When to use

- Several filters that can be on at once (materials, device types).
- Removable active filters above a list.

## Use something else when

| Need | Use |
|---|---|
| Exactly one of 2–5 options | SegmentedControl |
| A read-only status | Badge |

## Import

```tsx
import { Chip } from "@semi/ui";
```

## Examples

### Toggle filters

tone tints the chip while it is on; every chip on shows a check.

```tsx
"use client";

import { useState } from "react";
import { Chip } from "@semi/ui";

const MATERIALS = [
  { key: "pla", label: "PLA", tone: "green" },
  { key: "petg", label: "PETG", tone: "sky" },
  { key: "tpu", label: "TPU", tone: "pink" },
] as const;

export default function ChipToggle() {
  const [on, setOn] = useState<string[]>(["pla"]);
  const toggle = (k: string) => setOn((v) => (v.includes(k) ? v.filter((x) => x !== k) : [...v, k]));
  return (
    <div className="flex flex-wrap gap-2">
      {MATERIALS.map((m) => (
        <Chip key={m.key} tone={m.tone} active={on.includes(m.key)} onClick={() => toggle(m.key)}>
          {m.label}
        </Chip>
      ))}
    </div>
  );
}
```

## Accessibility

- A button with aria-pressed when it toggles; keep the text short.
- Selected shows a leading check (not colour alone); on a touch phone each chip is at least 44 × 44px, real size, so chips in a row never share a tap point.
