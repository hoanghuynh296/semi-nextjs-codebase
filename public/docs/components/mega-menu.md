# Mega menu

A flyout of links in category columns: a text-overline header per column, links with a grey icon, a hint and a New badge, and a See all link. AppShell opens it beside the sidebar from a nav item with mega; an app can open it from its own trigger.

## When to use

- One sidebar item leads to many destinations of one area that fall into 2–4 groups (a catalogue, tools, reports).
- A top-bar item of an app with that kind of area (placement="bottom").

## Use something else when

| Need | Use |
|---|---|
| 2–6 views of one area that people switch between often | AppShell sub-items (children) |
| Actions (create, export), not places | Menu |
| Top navigation of a website | NavigationMenu |

## Import

```tsx
import { MegaMenu } from "@semi/ui";
```

## Examples

### From a button

placement="bottom" under its own trigger; in AppShell it opens beside the sidebar.

```tsx
"use client";

import { useRef, useState } from "react";
import { Button, MegaMenu } from "@semi/ui";

export default function MegaMenuFlyout() {
  const [open, setOpen] = useState(false);
  const anchor = useRef<HTMLDivElement>(null);
  return (
    <div ref={anchor} className="inline-flex">
      <Button icon="box" aria-haspopup="dialog" aria-expanded={open} onClick={() => setOpen((v) => !v)}>
        Sản phẩm
      </Button>
      <MegaMenu
        open={open}
        onClose={() => setOpen(false)}
        anchorRef={anchor}
        placement="bottom"
        label="Sản phẩm"
        columns={[
          {
            title: "Danh mục",
            items: [
              { id: "printers", label: "Máy in", icon: "printer", href: "#", hint: "Máy in 3D và phụ kiện" },
              { id: "filament", label: "Nhựa in", icon: "layers", href: "#", hint: "PLA, PETG, TPU" },
            ],
          },
          {
            title: "Bán hàng",
            items: [
              { id: "prices", label: "Bảng giá", icon: "tag", href: "#" },
              { id: "bundles", label: "Combo", icon: "package", href: "#", isNew: true },
            ],
          },
        ]}
        seeAll={{ href: "#" }}
      />
    </div>
  );
}
```

## API

### MegaMenu

| Prop | Type | Default | Description |
|---|---|---|---|
| `open` * | `boolean` |  |  |
| `onClose` * | `() => void` |  | Called on Escape, a click outside, Tab out of the panel or a link chosen. |
| `anchorRef` * | `RefObject<HTMLElement \| null>` |  | The element the panel is placed against (a sidebar for `right`, a top-bar button for `bottom`). |
| `triggerRef` | `RefObject<HTMLElement \| null>` |  | Where focus returns when the menu closes; defaults to the element focused when it opened. |
| `label` * | `string` |  | Accessible name of the panel (the nav item's label). |
| `placement` | `'right' \| 'bottom'` | `"right"` | `right` beside the anchor (a sidebar), `bottom` under it (a top bar). |
| `onNavigate` | `(id: string) => void` |  | Called with the item id when a link is chosen (the link still navigates). |
| `columns` * | `MegaMenuColumn[]` |  |  |
| `seeAll` | `{ href: string; label?: string \| undefined; }` |  | Link to the full list; `label` defaults to the locale's `seeAll`. |

## Accessibility

- A non-modal dialog named after its trigger; the trigger has aria-haspopup="dialog" and aria-expanded.
- Focus moves to the first link; ↑/↓ move between links; Escape or a click outside closes it and focus returns to the trigger; Tab out of the panel closes it.
- Column headers are headings (h2) and each column is a labelled section.

## Notes

- In AppShell give the nav item `mega: { columns, seeAll }`: on phones the drawer shows the same links as a drill-down level.
- Column titles are written in sentence case: text-overline renders them uppercase (C-032, the only place besides sidebar and palette group labels).
- Give every link an icon, or none; at most one New badge per column.
