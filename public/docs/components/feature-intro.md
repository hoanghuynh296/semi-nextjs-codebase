# Feature intro

The first visit of a feature (L14): a small dialog with a visual, a title, one line, dots, “Bỏ qua” and “Tiếp” / “Bắt đầu”. Shown once per user per id; “seen” lives in a store (localStorage by default, pass your own to keep it per account). It waits while another dialog is open.

## When to use

- A new or reworked feature people already in the app should notice once (a new workspace, a new way to compare quotes).
- “Xem lại giới thiệu” from a Help menu (forceOpen).

## Use something else when

| Need | Use |
|---|---|
| A page that is empty on first use | GuidedEmptyState or EmptyState first-use |
| A one-line tip next to a control | Tooltip or a hint line |
| A decision or a confirmation | Modal / confirmDialog |

## Import

```tsx
import { FeatureIntro, localIntroStore, type FeatureIntroSlide, type FeatureIntroStore } from "@semi/ui";
```

## Examples

### Once per user

Mount it on the feature's page with an id; here a button shows it again (forceOpen).

```tsx
import { useState } from "react";
import { Button, FeatureIntro, IconTile } from "@semi/ui";

export default function FeatureIntroBasic() {
  const [replay, setReplay] = useState(0);
  return (
    <>
      <Button icon="sparkles" onClick={() => setReplay((n) => n + 1)}>
        Xem lại giới thiệu
      </Button>
      {replay > 0 && (
        <FeatureIntro
          key={replay}
          id="purchasing-workspace"
          forceOpen
          slides={[
            { title: "Yêu cầu mua trên một màn hình", body: "Mặt hàng, nhà cung cấp và lời nhắn ở bên trái, báo giá hiện bên phải khi về.", visual: <IconTile name="layers" size="lg" tone="gray" /> },
            { title: "So sánh từng mặt hàng", body: "Giá tốt nhất của mỗi dòng được đánh dấu, tổng tính theo số tấn bạn chọn.", visual: <IconTile name="chart" size="lg" tone="gray" /> },
            { title: "Gõ @ để nhắc nhà cung cấp", body: "Trong lời nhắn, @ gợi ý nhà cung cấp và / chèn mẫu thư có sẵn.", visual: <IconTile name="sparkles" size="lg" tone="gray" /> },
          ]}
        />
      )}
    </>
  );
}
```

### Your own store

Keep “seen” on the account instead of the browser.

```tsx
import { FeatureIntro, IconTile, type FeatureIntroStore } from "@semi/ui";

// "Seen" on the account: the app's own API (any async get / set works).
const accountStore: FeatureIntroStore = {
  get: async (id) => {
    const res = await fetch(`/api/me/intros/${id}`);
    return res.ok && (await res.json()).seen === true;
  },
  set: (id) => {
    void fetch(`/api/me/intros/${id}`, { method: "PUT" });
  },
};

export default function FeatureIntroStoreExample() {
  return (
    <FeatureIntro
      id="purchasing-workspace"
      store={accountStore}
      slides={[{ title: "Yêu cầu mua trên một màn hình", body: "Mặt hàng và nhà cung cấp bên trái, báo giá bên phải.", visual: <IconTile name="layers" size="lg" tone="gray" /> }]}
    />
  );
}
```

## API

### FeatureIntro

| Prop | Type | Default | Description |
|---|---|---|---|
| `id` * | `string` |  | One id per feature ("purchasing-workspace"): shown once per id. |
| `slides` * | `FeatureIntroSlide[]` |  | One to four slides. |
| `store` | `FeatureIntroStore` | `localIntroStore` | Where "seen" is read and written (default `localIntroStore`). |
| `forceOpen` | `boolean` | `false` | Show it even if seen (a Help menu's "Xem lại giới thiệu", docs). Still waits for other dialogs to close. |
| `onDone` | `(how: 'finished' \| 'skipped') => void` |  | After it closes and is stored as seen: `finished` from the last slide's primary, `skipped` from Skip, Escape or the backdrop. |
| `skipLabel` | `string` |  | Default "Bỏ qua". |
| `nextLabel` | `string` |  | Default "Tiếp". |
| `doneLabel` | `string` |  | Primary on the last slide; default "Bắt đầu". |

## Accessibility

- A modal dialog named by the slide's title and described by its line: focus moves to the primary, Tab stays inside, Escape and the backdrop skip, focus returns to where it was.
- It never opens over another dialog: it waits until no aria-modal dialog is on the page, and only one FeatureIntro is open at a time (a second unseen one follows when the first closes). The step (“Bước 1 / 3”) is screen-reader text; the dots are decorative.

## Notes

- The store is read after mount only, so the server HTML never contains the dialog; blocked storage counts as seen.
- At most three slides; one sentence each. One FeatureIntro per page.
