# Page title

PageTitle is the large display title of a page (text only). PageTabsTitle turns it into 2–4 underline tabs for sibling pages.

## When to use

- The first line of every page (PageTitle).
- 2–4 sibling views of one area: Máy in / Job in (PageTabsTitle).

## Use something else when

| Need | Use |
|---|---|
| Tabs inside a card or panel | Tabs |
| A filter | Pills |

## Import

```tsx
import { PageTitle, PageTabsTitle } from "@semi/ui";
```

## Examples

### PageTitle

```tsx
import { PageTitle } from "@semi/ui";

export default function PageTitleBasic() {
  return <PageTitle title="Máy in" />;
}
```

### PageTabsTitle

```tsx
"use client";

import { useState } from "react";
import { PageTabsTitle } from "@semi/ui";

export default function PageTabsTitleBasic() {
  const [view, setView] = useState<"printers" | "jobs">("printers");
  return (
    <PageTabsTitle
      value={view}
      onChange={setView}
      tabs={[
        { key: "printers", label: "Máy in" },
        { key: "jobs", label: "Job in" },
      ]}
    />
  );
}
```

### PageTabsTitle

Underline display tabs used when a view groups 2–4 sibling sub-pages (e.g. "Máy in / Job in", "Sản phẩm / Danh mục").
Replaces putting a separate <Pills> bar directly under a <PageTitle>.

| Prop | Type | Default | Description |
|---|---|---|---|
| `tabs` * | `PageTabOption<T>[]` |  |  |

| `onChange` * | `(key: T) => void` |  |  |
| `ariaLabel` | `string` |  |  |
| `className` | `string` | `""` |  |

## Accessibility

- PageTitle is the page h1. PageTabsTitle is a tablist with arrow-key navigation.

## Notes

- No subtitle under the title and no text buttons on the title row: actions go to PageActions or the toolbar.
