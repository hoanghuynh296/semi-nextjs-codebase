# Accordion

A list of sections where one (or several) open at a time: FAQs, settings groups, help.

## When to use

- FAQs and help; long settings split into groups.

## Use something else when

| Need | Use |
|---|---|
| One section | Collapsible |
| Switch whole panels | Tabs |

## Import

```tsx
import { Accordion } from "@semi/ui";
```

## Examples

### FAQ

```tsx
import { Accordion } from "@semi/ui";

export default function AccordionFaq() {
  return (
    <Accordion
      defaultValue={["petg"]}
      items={[
        { key: "petg", title: "Vì sao PETG bị kéo sợi?", content: "Giảm nhiệt độ 5–10°C, tăng retraction và bật Z-hop." },
        { key: "warp", title: "Bản in bị cong góc?", content: "Lau bàn bằng cồn, dùng brim 5 mm và tắt quạt ở 3 lớp đầu." },
        { key: "clog", title: "Đầu phun bị tắc phải làm sao?", content: "Chạy cold pull 2–3 lần; nếu vẫn tắc, thay đầu phun." },
      ]}
    />
  );
}
```

### Several open

```tsx
import { Accordion } from "@semi/ui";

export default function AccordionMultiple() {
  return (
    <Accordion
      type="multiple"
      defaultValue={["network", "storage"]}
      items={[
        { key: "network", title: "Mạng", content: "Wi-Fi: Xuong-A · IP 192.168.1.42" },
        { key: "storage", title: "Bộ nhớ", content: "Đã dùng 12,4 / 32 GB" },
        { key: "firmware", title: "Firmware", content: "1.08 (mới nhất)", disabled: true },
      ]}
    />
  );
}
```

## API

### Accordion

A list of sections, one (type="single", default) or several (type="multiple") open at a time. ↑/↓ move between
headers, Home / End jump; each header is a button inside a heading (level), its panel a labelled region.

| Prop | Type | Default | Description |
|---|---|---|---|
| `items` * | `AccordionItem[]` |  |  |
| `type` | `'single' \| 'multiple'` | `"single"` |  |
| `value` | `string[]` |  | Open item keys (controlled). |
| `defaultValue` | `string[]` | `[]` |  |
| `onChange` | `(open: string[]) => void` |  |  |
| `headingLevel` | `2 \| 3 \| 4 \| 5 \| 6` | `3` | Heading level of the headers in the page outline. |
| `className` | `string` |  |  |

## Accessibility

- Each header is a button inside a heading (headingLevel), with aria-expanded; ↑/↓ Home End move between headers; panels are labelled regions.
