# Input OTP

One-time code entry (OTP, PIN, 2FA): boxes on screen, one real input underneath, so paste, SMS autofill, screen readers and the number keypad work like a normal field.

## When to use

- Verification codes, PINs, invite codes of a fixed length.

## Use something else when

| Need | Use |
|---|---|
| A password | Input type="password" (+ InputGroup reveal button) |

## Import

```tsx
import { InputOTP } from "@semi/ui";
```

## Examples

### 6-digit code

```tsx
"use client";

import { useState } from "react";
import { Field, InputOTP, toast } from "@semi/ui";

export default function InputOTPBasic() {
  const [code, setCode] = useState("");
  const [error, setError] = useState(false);
  return (
    <Field label="Mã xác thực" hint="Gửi tới số điện thoại ****321" error={error ? "Mã không đúng, thử lại." : undefined}>
      <InputOTP
        value={code}
        onChange={(v) => {
          setCode(v);
          setError(false);
        }}
        onComplete={(v) => (v === "123456" ? toast({ title: "Đã xác thực", tone: "success" }) : setError(true))}
        invalid={error}
      />
    </Field>
  );
}
```

## API

### InputOTP

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` * | `string` |  |  |
| `onChange` * | `(value: string) => void` |  |  |
| `onComplete` | `(value: string) => void` |  | Called once every box is filled. |
| `length` | `number` | `6` |  |
| `type` | `'numeric' \| 'text'` | `"numeric"` | numeric: digits and the number keypad; text: letters and digits. |
| `label` | `string` |  | Accessible name (default “Mã xác thực”). Put a visible label in Field around it when you have one. |
| `groupSize` | `number` | `3` | Visual gap after every N boxes (0: none). |
| `disabled` | `boolean` | `false` |  |
| `invalid` | `boolean` | `false` | Error look (wrong code). |
| `autoFocus` | `boolean` | `false` |  |
| `className` | `string` |  |  |

## Accessibility

- A single labelled input with autocomplete="one-time-code" and inputmode="numeric"; the boxes are decoration; invalid sets aria-invalid.
