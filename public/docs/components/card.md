# Card

The bento content card: the card surface (bg-card, separated from the page by tone, no visible border in Flat and Soft) with the style's radius and resting shadow. bordered frames a dense data view; interactive adds hover / press, active marks the selected or running item.

## When to use

- Group the content of a page in cards; nested facts in TILE (bg-card-field).
- bordered for a dense data view (a table or rows that need an edge).

## Use something else when

| Need | Use |
|---|---|
| A metric | KpiCard |
| A tinted callout | Alert or TONAL_CONTAINER |

## Import

```tsx
import { Card, CARD, CARD_BORDERED, CARD_HOVER, CARD_ACTIVE, TILE } from "@semi/ui";
```

## API

### Card

With `onClick` the card is a button for keyboards and screen readers too: role="button", in the tab order, Enter and
Space click it, FOCUS_RING shows focus (a plain <div onClick> is mouse-only). `active` is then its pressed state.
A card that opens another page wraps a next/link around its title instead.

| Prop | Type | Default | Description |
|---|---|---|---|
| `interactive` | `boolean` | `false` | Clickable card (opens a detail view): hover border + press scale. |
| `active` | `boolean` |  | "On" / selected card: primary border, no glow. On a card with onClick it is also its pressed state (aria-pressed). |
| `bordered` | `boolean` | `false` | Framed card for dense data views (a table or rows that need an edge): panel fill + 1px line instead of the borderless card surface. |
| `padding` | `'card' \| 'panel' \| 'none'` | `"card"` | Inner padding: `"card"` = p-card (16px at regular density, the default), `"panel"` = p-card sm:p-panel (a roomy card, 24px from sm), `"none"` for an image or a table that runs to the edge. A padding class in `className` (p-*, px-*, py-*) replaces it. |
| `ref` | `React.Ref<HTMLDivElement>` |  |  |

## Accessibility

- With onClick the card is a button for keyboards and screen readers (role="button", tab order, Enter / Space, focus ring); active becomes aria-pressed. Never a div with onClick (semi-lint click-target).
- A card that opens another page puts a next/link on its title instead of onClick.

## Notes

- It pads itself: padding="card" (p-card, default), "panel" (p-card sm:p-panel) or "none" for an image or table to the edge. Never tighter than p-card (card-padding); a p-* in className replaces the default.
- Pass padding and layout only: no bg-* or shadow-* on <Card> (card-class-override).
- Light: the card is recessed one step below the app; dark: one step above the panel. A block meant as a card uses bg-card (or Card), never bg-panel: panel is the sidebar / modal step.
