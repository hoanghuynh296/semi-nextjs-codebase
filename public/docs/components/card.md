# Card

The bento content card: panel fill and the style's card border, radius and resting shadow. interactive adds hover / press, active marks the selected or running item.

## When to use

- Group the content of a page in cards; nested facts in TILE.

## Use something else when

| Need | Use |
|---|---|
| A metric | KpiCard |
| A tinted callout | Alert or TONAL_CONTAINER |

## Import

```tsx
import { Card, CARD, CARD_HOVER, CARD_ACTIVE, TILE } from "@semi/ui";
```

## Examples

### Content card

```tsx
import { Badge, Card } from "@semi/ui";

export default function CardBasic() {
  return (
    <Card className="p-4 space-y-2 max-w-sm">
      <div className="flex items-center justify-between gap-2">
        <span className="text-ui font-semibold text-contrast">X1 Carbon · Xưởng A</span>
        <Badge tone="emerald" dot>
          Online
        </Badge>
      </div>
      <p className="text-label text-muted">Đang in: vỏ hộp điều khiển · còn 42 phút</p>
    </Card>
  );
}
```

### Interactive and active

```tsx
import { Card, TILE } from "@semi/ui";

export default function CardStates() {
  return (

      <Card interactive active className="p-4 space-y-2">
        <div className="text-ui font-semibold text-contrast">A1 Mini · đang in</div>
        <div className={`${TILE} p-2 text-label text-body tabular-nums`}>Tiến độ 64%</div>
      </Card>
    </div>
  );
}
```

## API

### Card

| Prop | Type | Default | Description |
|---|---|---|---|
| `interactive` | `boolean` | `false` | Clickable card (opens a detail view): hover border + press scale. |
| `active` | `boolean` | `false` | "On" / selected card: primary border, no glow. |
| `ref` | `React.Ref<HTMLDivElement>` |  |  |

## Accessibility

- A clickable card is a link or button inside the card, not a div with onClick.

## Notes

- Pass padding and layout only: no bg-* or shadow-* on <Card> (card-class-override).
