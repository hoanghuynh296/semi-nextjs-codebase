# Card actions

Quick actions on a card or media tile: round icon buttons in the top right corner that show on hover or keyboard focus where the device can hover, and one always-visible ⋯ with every action on touch screens. Goes inside a `group relative` card.

## When to use

- Cards and media tiles in a grid (suppliers, products, templates, files) that open on click and have one or two quick actions.
- A card's ⋯ overflow (G4 for grids: one or two inline actions at most, the rest in ⋯, danger last).

## Use something else when

| Need | Use |
|---|---|
| Actions of a table row | Menu (row ⋯) |
| Actions on several selected cards | the bulk bar (D7) |

## Import

```tsx
import { CardActions, type CardAction } from "@semi/ui";
```

## Examples

### Card grid

```tsx
"use client";

import { CardActions, IconTile, Item, toast } from "@semi/ui";

const SUPPLIERS = [
  { id: "s1", name: "Gia vị Tây Nguyên", region: "Đắk Lắk" },
  { id: "s2", name: "Hồ tiêu Chư Sê", region: "Gia Lai" },
  { id: "s3", name: "Quế Trà My", region: "Quảng Nam" },
];

// Hover (or Tab into) a card: Gửi hỏi giá, Ghim and ⋯. On a touch screen only the ⋯ shows, with every action.
export default function CardActionsGrid() {
  return (
    <div className="grid grid-cols-1 sm:grid-cols-3 gap-3">
      {SUPPLIERS.map((s) => (
        <div key={s.id} className="group relative rounded-card bg-card">
          <Item media={<IconTile name="store" tone="gray" size="md" />} title={s.name} description={s.region} onClick={() => toast({ title: `Mở ${s.name}` })} className="pr-24 rounded-card" />
          <CardActions
            label={`Thao tác với ${s.name}`}
            actions={[
              { icon: "send", label: "Gửi hỏi giá", onClick: () => toast({ title: `Gửi hỏi giá ${s.name}` }) },
              { icon: "pin", label: "Ghim", onClick: () => toast({ title: "Đã ghim" }) },
            ]}
            menu={[
              { label: "Sửa", icon: "edit", onSelect: () => toast({ title: "Sửa" }) },
              { label: "Ngừng hợp tác", icon: "block", danger: true, onSelect: () => toast({ title: "Đã ngừng", tone: "danger" }) },
            ]}
          />
        </div>
      ))}
    </div>
  );
}
```

## API

### CardActions

| Prop | Type | Default | Description |
|---|---|---|---|
| `actions` | `CardAction[]` | `[]` | One or two icon actions shown on hover (on touch they move into the ⋯ menu). |
| `menu` | `MenuItem[]` |  | The rest, in the ⋯ menu (danger last). |
| `label` * | `string` |  | Name of the ⋯ menu, with the item it acts on: "Thao tác với Gia vị Tây Nguyên". Required: on touch it is the only control. |
| `className` | `string` |  |  |

## Accessibility

- A group named by `label` (with the item's name); every icon button has an aria-label and a title; the hover row is in the tab order and shows on focus; on touch the ⋯ is always visible, so it never depends on hover.
- Clicks inside do not reach the card under it.
