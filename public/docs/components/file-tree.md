# File tree

Files and folders as a keyboard tree, with A / M / D marks for what an agent added, modified or deleted; select a file to open it.

## When to use

- Changes an agent made, a repo or export browser, attachments with folders.

## Use something else when

| Need | Use |
|---|---|
| A flat list of files | Item in an ItemGroup |

## Import

```tsx
import { FileTree, type FileNode } from "@semi/ui";
```

## Examples

### Changed files

```tsx
"use client";

import { useState } from "react";
import { FileTree, type FileNode } from "@semi/ui";

const FILES: FileNode[] = [
  {
    name: "src",
    children: [
      { name: "components", children: [{ name: "PrinterCard.tsx", change: "modified" }, { name: "QueueList.tsx", change: "added" }, { name: "OldQueue.tsx", change: "deleted" }] },
      { name: "app.tsx" },
    ],
  },
  { name: "package.json", change: "modified" },
  { name: "README.md" },
];

export default function FileTreeChanges() {
  const [file, setFile] = useState("src/components/PrinterCard.tsx");
  return (
    <div className="grid gap-3 @xl:grid-cols-[240px_1fr]">
      <FileTree label="Tệp đã thay đổi" files={FILES} selected={file} onSelect={setFile} className="rounded-card border border-line bg-panel p-1.5" />
      <div className="rounded-card border border-line p-3 text-label text-muted break-all">{file}</div>
    </div>
  );
}
```

## API

### FileTree

Files and folders (a repo, a diff, an export): a keyboard tree (role="tree"). ↑/↓ move, → opens a folder or enters
it, ← closes it or goes to the parent, Home / End, Enter selects a file (or toggles a folder). Paths are the names
joined by "/".

| Prop | Type | Default | Description |
|---|---|---|---|
| `files` * | `FileNode[]` |  |  |
| `label` * | `string` |  | Accessible name of the tree. |
| `selected` | `string` |  | Path of the selected file. |
| `onSelect` | `(path: string, node: FileNode) => void` |  |  |
| `defaultExpanded` | `string[]` |  | Folder paths open at first (default: every folder). |
| `className` | `string` |  |  |

## Accessibility

- role="tree" with treeitems (aria-level, aria-expanded, aria-selected); ↑/↓, →/← open and close, Home / End, Enter selects; change marks have text for screen readers.
