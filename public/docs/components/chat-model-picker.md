# Chat model picker

Provider → model → effort chips, for the toolbar of a chat composer. The lists are app data.

## When to use

- Let people pick the provider, model and thinking effort of an AI feature.

## Import

```tsx
import { ChatModelPicker, CHAT_PICK_CHIP } from "@semi/ui";
```

## Examples

### Provider, model, effort

```tsx
"use client";

import { useState } from "react";
import { ChatModelPicker, Icon } from "@semi/ui";

const PROVIDERS = [
  { id: "claude", name: "Claude", models: [{ id: "opus", label: "Opus 5.5", efforts: true }, { id: "haiku", label: "Haiku 5.5" }] },
  { id: "local", name: "Ollama (máy này)", models: [{ id: "llama", label: "llama-local" }] },
];

export default function ChatModelPickerBasic() {
  const [provider, setProvider] = useState("claude");
  const [model, setModel] = useState("opus");
  const [effort, setEffort] = useState("");
  const current = PROVIDERS.find((p) => p.id === provider)!;
  const hasEffort = current.models.find((m) => m.id === model && "efforts" in m);
  return (
    <ChatModelPicker
      providers={PROVIDERS.map((p) => ({ value: p.id, label: p.name, icon: <Icon name="sparkles" className="w-3.5 h-3.5" /> }))}
      provider={provider}
      onProviderChange={(v) => {
        setProvider(v);
        setModel(PROVIDERS.find((p) => p.id === v)!.models[0].id);
      }}
      models={current.models.map((m) => ({ value: m.id, label: m.label }))}
      model={model}
      onModelChange={setModel}
      efforts={hasEffort ? [{ value: "", label: "Tự động" }, { value: "high", label: "Nghĩ kỹ" }] : []}
      effort={effort}
      onEffortChange={setEffort}
    />
  );
}
```

## API

### ChatModelPicker

Provider, model and thinking-effort chips, like the model picker of the Claude / Gemini apps; pass it as the
composer `toolbar`. UI only: the app lists what is ready and remembers the pick. The provider chip shows only when
more than one provider is offered, as its logo (`icon`; the name is the tooltip and the label in the list); the
effort chip only when the model takes one. The chips stay usable while an answer streams (the pick applies to the
next question).

| Prop | Type | Default | Description |
|---|---|---|---|
| `providers` | `CustomSelectOption[]` | `[]` | Ready providers / profiles (Claude, OpenAI, a local server…): `icon` = its logo in the text colour. |
| `provider` | `string` |  |  |
| `onProviderChange` | `(value: string) => void` |  |  |
| `models` * | `CustomSelectOption[]` |  | The current provider's models (`title` e.g. "default of this provider"). |
| `model` * | `string` |  |  |
| `onModelChange` * | `(value: string) => void` |  |  |
| `efforts` | `CustomSelectOption[]` | `[]` | Thinking levels the current model takes (empty = no effort chip). |
| `effort` | `string` |  |  |
| `onEffortChange` | `(value: string) => void` |  |  |
| `disabled` | `boolean` | `false` |  |

## Accessibility

- Each chip is a select button with its own label; changing the provider resets the model.
