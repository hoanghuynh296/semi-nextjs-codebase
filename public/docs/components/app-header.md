# App header

The top bar of a stand-alone tool app: logo + title go home, the module name, and one primary action on the right. No Home button.

## When to use

- Single-screen tools: 3D editors, slicers, colour tools.

## Use something else when

| Need | Use |
|---|---|
| An app with several pages | AppShell |

## Import

```tsx
import { AppHeader, HEADER_ICON_BTN, HEADER_ICON_OFF, headerPrimary } from "@semi/ui";
```

## Examples

### Tool app

```tsx
import { AppHeader, HEADER_ICON_BTN, HEADER_ICON_OFF, Icon, headerPrimary } from "@semi/ui";

export default function AppHeaderTool() {
  return (
    <div className="rounded-card border border-line overflow-hidden">
      <AppHeader title="Phối màu" productName="3D Noobs" logoIcon="palette" homeHref="#">
        <button type="button" className={`${HEADER_ICON_BTN} ${HEADER_ICON_OFF}`} aria-label="Trợ lý AI" title="Trợ lý AI">
          <Icon name="sparkles" className="w-4 h-4" />
        </button>
        <button type="button" className={headerPrimary(true)}>
          Xong
        </button>
      </AppHeader>
    </div>
  );
}
```

## API

### AppHeader

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` | `string` |  | Stand-alone app title; without it the bar is the home page's logo bar. |
| `children` | `React.ReactNode` |  | Right-hand side (app actions). Wrap in a `flex-1` element to centre something. |
| `onHome` | `() => void` |  | Click on the logo + title. Default: plain link to `/`. |
| `hideTitleOnPhone` | `boolean` | `false` | Only the logo on phones (dense toolbars). |
| `className` | `string` | `""` |  |
| `productName` | `string` | `"Semi"` | Product name shown on the home bar (no `title`). |
| `logo` | `React.ReactNode` |  | Custom logo node; replaces the default icon tile. |
| `logoIcon` | `IconName` | `"sparkles"` | Icon of the default logo tile. |
| `homeHref` | `string` | `"/"` | Where the logo + title link goes. |
| `homeLabel` | `string` |  | Tooltip / aria text of the logo link. |

## Accessibility

- A banner landmark; the home link is labelled; icon buttons need aria-label.
