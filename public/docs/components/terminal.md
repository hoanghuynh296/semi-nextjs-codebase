# Terminal

A command and its output: streams and follows the end (unless people scroll up), shows a spinner while running and the exit code when done, with a copy button.

## When to use

- Agents and jobs that run shell commands, builds, deploy logs.

## Use something else when

| Need | Use |
|---|---|
| A snippet to copy | CodeBlock |
| A tool call with JSON in / out | ToolCall |

## Import

```tsx
import { Terminal } from "@semi/ui";
```

## Examples

### A build that streams

```tsx
"use client";

import { useEffect, useState } from "react";
import { Button, Terminal } from "@semi/ui";

const LINES = ["> semi-docs@0.12.0 build", "> next build", "", "  Next.js 16", "  Creating an optimized production build", "  Compiled successfully", "  Generating static pages (128/128)", "", "Done in 14.2s"];

export default function TerminalRun() {
  const [n, setN] = useState(LINES.length);
  const running = n < LINES.length;
  useEffect(() => {
    if (!running) return;
    const id = setTimeout(() => setN((x) => x + 1), 400);
    return () => clearTimeout(id);
  }, [running, n]);
  return (
    <div className="flex flex-col gap-3 max-w-xl">
      <Terminal command="npm run build" output={LINES.slice(0, n).join("\n")} status={running ? "running" : "done"} exitCode={0} maxHeight={220} />
      <Terminal command="npm test" output={"FAIL tests/queue.test.ts\n1 failed, 42 passed"} exitCode={1} />
      <div>
        <Button size="sm" variant="secondary" icon="play" onClick={() => setN(0)}>
          Chạy lại
        </Button>
      </div>
    </div>
  );
}
```

## API

### Terminal

Follows the end of the output while it streams, unless people scrolled up to read. The log is focusable (keyboard
scrolling) and not a live region: output read aloud line by line would drown everything else.

| Prop | Type | Default | Description |
|---|---|---|---|
| `command` | `string` |  | The command line, shown first after “$”. |
| `output` * | `string` |  |  |
| `title` | `string` |  | Name above the output (default: the command). |
| `status` | `'running' \| 'done'` | `"done"` |  |
| `exitCode` | `number` |  | Shown once done: 0 green, anything else red. |
| `maxHeight` | `number` | `320` | Height in px before the output scrolls. |
| `className` | `string` |  |  |

## Accessibility

- The log is focusable for keyboard scrolling and not a live region (streamed lines are not read aloud); status is text (exit code).
