# Breadcrumb

Where the page sits: a trail of links ending with the current page. Long trails collapse their middle into a “…” menu.

## When to use

- Detail pages deep in a hierarchy (Kho › Vật liệu › PLA đen).

## Use something else when

| Need | Use |
|---|---|
| Top-level pages of an app | AppShell navigation |
| Sibling views | PageTabsTitle |

## Import

```tsx
import { Breadcrumb } from "@semi/ui";
```

## Examples

### Trail

```tsx
import { Breadcrumb } from "@semi/ui";

export default function BreadcrumbBasic() {
  return (
    <Breadcrumb
      items={[
        { label: "Kho", href: "/inventory", icon: "box" },
        { label: "Vật liệu", href: "/inventory/materials" },
        { label: "PLA đen 1kg" },
      ]}
    />
  );
}
```

### Collapsed

More items than maxItems keep the first and the last two; the rest open from “…”.

```tsx
import { Breadcrumb } from "@semi/ui";

export default function BreadcrumbCollapsed() {
  return (
    <Breadcrumb
      maxItems={3}
      items={[
        { label: "Xưởng", href: "/" },
        { label: "Khu A", href: "/a" },
        { label: "Dãy 2", href: "/a/2" },
        { label: "Máy in", href: "/a/2/printers" },
        { label: "X1 Carbon 03" },
      ]}
    />
  );
}
```

## API

### Breadcrumb

| Prop | Type | Default | Description |
|---|---|---|---|
| `items` * | `BreadcrumbItem[]` |  |  |
| `maxItems` | `number` | `4` | More items than this collapse the middle ones into a "…" menu (first + last two stay). |
| `className` | `string` |  |  |

## Accessibility

- A nav landmark (“Đường dẫn”) with an ordered list; the last item has aria-current="page".
