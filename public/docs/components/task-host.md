# Task host

startTask() shows one blocking overlay for a job the user must wait for: label, current step, progress, elapsed time and an optional Cancel. Mount TaskHost once in the root layout, next to ToastHost and ConfirmHost.

## When to use

- The user started a job and cannot do anything useful until it finishes: an upload before printing, an import, a firmware update, a payment step, an AI job that the next screen needs.

## Use something else when

| Need | Use |
|---|---|
| Work the user can keep going during (a background sync, an export) | Progress inline, or toast() when it ends |
| A page or section waiting for its data | Skeleton |
| A button running its own short action | Button loading |

## Import

```tsx
import { TaskHost, startTask } from "@semi/ui";
```

## Examples

### Steps, progress, timer and Cancel

```tsx
"use client";

import { Button, startTask, toast } from "@semi/ui";

const STEPS = ["Kiểm tra file", "Gửi file lên máy in", "Cắt lớp"];

export default function TaskHostUpload() {
  const run = () => {
    let stopped = false;
    const task = startTask({
      label: "Tải file lên máy in",
      step: STEPS[0],
      value: 0,
      timer: true,
      onCancel: () => {
        stopped = true;
        toast({ title: "Đã huỷ tải lên" });
      },
    });
    let value = 0;
    const tick = setInterval(() => {
      if (stopped) return clearInterval(tick);
      value += 10;
      task.update({ value, step: STEPS[Math.min(STEPS.length - 1, Math.floor(value / 34))] });
      if (value >= 100) {
        clearInterval(tick);
        task.done();
        toast({ title: "Đã gửi file tới máy in", tone: "success" });
      }
    }, 400);
  };
  return (
    <Button variant="primary" onClick={run}>
      Tải lên và in
    </Button>
  );
}
```

### No Cancel, ends with fail()

fail() closes the overlay and shows a danger toast.

```tsx
"use client";

import { Button, startTask } from "@semi/ui";

export default function TaskHostFail() {
  const run = () => {
    // No onCancel: a firmware update cannot stop halfway, so there is no Cancel button and Escape does nothing.
    const task = startTask({ label: "Cập nhật firmware", step: "Đang ghi bộ nhớ máy in" });
    setTimeout(() => task.fail("Cập nhật firmware thất bại", "Máy in mất kết nối. Thử lại khi máy online."), 2500);
  };
  return (
    <Button onClick={run}>
      Cập nhật firmware (lỗi)
    </Button>
  );
}
```

## API

### TaskHost

Mounted once in the root layout; renders the task started by `startTask()`.

No props of its own.

## Accessibility

- An alertdialog named by the label, aria-busy while it runs; label and step sit in a polite live region, the elapsed time is not announced.
- Focus stays inside (on Cancel when there is one); Escape and Cancel only exist when onCancel is set.

## Notes

- <TaskHost /> goes once in the root layout (see Theme › Root layout); startTask() works from any event handler.
- One task at a time: startTask() while one runs replaces it, and the old handle does nothing. update({ value }) takes 0–100; leave value out for an indeterminate bar.
- Cancel and Escape close the overlay first, then call onCancel: stop the job there.
