# Code block

Code to read or copy: a mono block with a copy button and an optional title (file name); long lines scroll sideways. Plain text, no highlighting.

## When to use

- API keys and commands to copy, config snippets, developer docs.

## Use something else when

| Need | Use |
|---|---|
| A short value inline | <code> in text, or Kbd for keys |

## Import

```tsx
import { CodeBlock } from "@semi/ui";
```

## Examples

### With a file name

```tsx
import { CodeBlock } from "@semi/ui";

export default function CodeBlockBasic() {
  return (
    <div className="space-y-3">
      <CodeBlock code="npx semi-brand preview" />
      <CodeBlock
        title="app/globals.css"
        code={`@import "tailwindcss";
@import "@semi/ui/tokens.css";
@import "@semi/ui/base.css";`}
      />
    </div>
  );
}
```

- The block is focusable so keyboard users can scroll it; the copy button is labelled and says when it copied.
