# Checkbox

A native checkbox with label and description, checked fill in the accent, and an indeterminate state for “select all”.

## When to use

- Opt in to something in a form (accept terms, include archived).
- Select rows; “select all” with indeterminate.

## Use something else when

| Need | Use |
|---|---|
| A setting that applies at once | Switch |
| Exactly one option of a few | RadioGroup |

## Import

```tsx
import { Checkbox } from "@semi/ui";
```

## Examples

### With description

```tsx
"use client";

import { useState } from "react";
import { Checkbox } from "@semi/ui";

export default function CheckboxBasic() {
  const [auto, setAuto] = useState(true);
  return <Checkbox checked={auto} onChange={setAuto} label="Tự động in khi rảnh" description="Máy nhận job tiếp theo trong hàng đợi." />;
}
```

### Indeterminate and disabled

```tsx
"use client";

import { useState } from "react";
import { Checkbox } from "@semi/ui";

export default function CheckboxStates() {
  const [all, setAll] = useState(false);
  return (
    <div className="flex flex-col gap-3">
      <Checkbox checked={all} indeterminate={!all} onChange={setAll} label="Chọn tất cả" />
      <Checkbox checked={false} onChange={() => undefined} label="Không khả dụng" disabled />
    </div>
  );
}
```

### Row selection without a visible label

aria-label names each box ("Chọn đơn #1024").

```tsx
"use client";

import { useState } from "react";
import { Checkbox } from "@semi/ui";

const ORDERS = ["1024", "1025", "1026"];

export default function CheckboxRowSelect() {
  const [picked, setPicked] = useState<string[]>(["1025"]);
  const toggle = (o: string, on: boolean) => setPicked(on ? [...picked, o] : picked.filter((x) => x !== o));
  return (
    <ul className="divide-y divide-divider border border-line rounded-card">
      {ORDERS.map((o) => (
        <li key={o} className="flex items-center gap-3 px-3 py-2.5">
          <Checkbox checked={picked.includes(o)} onChange={(on) => toggle(o, on)} aria-label={`Chọn đơn #${o}`} />
          <span className="text-ui text-body tabular-nums">Đơn #{o}</span>
        </li>
      ))}
    </ul>
  );
}
```

## API

### Checkbox

| Prop | Type | Default | Description |
|---|---|---|---|
| `checked` * | `boolean` |  |  |
| `onChange` * | `(checked: boolean) => void` |  |  |
| `label` | `React.ReactNode` |  | Visible label; it names the checkbox and is part of the hit area. |
| `description` | `React.ReactNode` |  |  |
| `indeterminate` | `boolean` | `false` | Mixed state ("some selected") for a select-all box. |
| `disabled` | `boolean` | `false` |  |
| `id` | `string` |  |  |
| `className` | `string` |  |  |
| `aria-label` | `string` |  | Name for screen readers when there is no visible `label` (a row's select box: "Chọn đơn #1024"). `label` wins. |
| `aria-labelledby` | `string` |  | Id of the element that names the checkbox when its text is elsewhere (a table cell, a card title). `label` wins. |

## Accessibility

- A real <input type="checkbox">: Space toggles, label clicks toggle, description is linked.
- Without a visible label (row selection) give aria-label or aria-labelledby (label wins); in development a checkbox with no name logs a warning.
- On touch screens (any coarse pointer) the hit area is 44 × 44 px around the box; the visible size and layout do not change.
