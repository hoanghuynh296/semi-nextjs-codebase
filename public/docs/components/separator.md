# Separator

A thin divider between groups of content: horizontal, vertical, or with a short label in the middle (“hoặc”).

## When to use

- Split groups inside a card or menu; “hoặc” between two ways to sign in.
- A vertical rule between toolbar groups.

## Use something else when

| Need | Use |
|---|---|
| Space between sections | a gap (space-y-*) — most layouts need no line |

## Import

```tsx
import { Separator } from "@semi/ui";
```

## Examples

### Horizontal, label and vertical

```tsx
import { Button, Separator } from "@semi/ui";

export default function SeparatorBasic() {
  return (
    <div className="space-y-4 max-w-sm">
      <p className="text-ui text-body">Thông tin máy in</p>
      <Separator />
      <Button variant="primary" fullWidth>
        Đăng nhập bằng email
      </Button>
      <Separator label="hoặc" />
      <Button fullWidth>Đăng nhập bằng Google</Button>
      <div className="flex h-6 items-center gap-3 text-label text-muted">
        <span>Máy in</span>
        <Separator orientation="vertical" />
        <span>Vật liệu</span>
      </div>
    </div>
  );
}
```

## API

### Separator

| Prop | Type | Default | Description |
|---|---|---|---|
| `orientation` | `'horizontal' \| 'vertical'` | `"horizontal"` |  |
| `label` | `React.ReactNode` |  | Short text in the middle of a horizontal line ("hoặc"). |
| `decorative` | `boolean` | `true` | true (default): purely visual, hidden from screen readers. false: announced as a separator. |
| `className` | `string` |  |  |

## Accessibility

- Decorative by default (hidden from screen readers); decorative={false} announces a separator.
