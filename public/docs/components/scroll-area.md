# Scroll area

A fixed-size scrolling region (a long list in a card, a log). Semi hides scrollbars, so it marks the edges that have more content, can show a thin scrollbar, and is reachable by keyboard.

## When to use

- A list or log inside a card that must keep its height.

## Use something else when

| Need | Use |
|---|---|
| A wide table | Table (scrolls sideways by itself) |

## Import

```tsx
import { ScrollArea } from "@semi/ui";
```

## Examples

### Log in a card

```tsx
import { Card, ScrollArea } from "@semi/ui";

const LINES = Array.from({ length: 24 }, (_, i) => `12:${String(i).padStart(2, "0")}  Lớp ${i + 120}/310 · đầu phun 220°C`);

export default function ScrollAreaLog() {
  return (
    <Card className="p-0 max-w-md">
      <ScrollArea label="Nhật ký in" className="h-48">
        <ul className="p-3 space-y-1 text-label text-body tabular-nums">
          {LINES.map((l) => (
            <li key={l}>{l}</li>
          ))}
        </ul>
      </ScrollArea>
    </Card>
  );
}
```

## API

### ScrollArea

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` * | `string` |  | Accessible name of the region (it is focusable when it scrolls, so keyboard users can scroll it). |
| `orientation` | `'horizontal' \| 'vertical' \| 'both'` | `"vertical"` |  |
| `scrollbar` | `boolean` | `false` | Show a thin scrollbar (hidden everywhere else in Semi). |
| `className` | `string` |  | Give it a size here: "h-64", "max-h-80", "w-full". |
| `children` * | `React.ReactNode` |  |  |

## Accessibility

- A labelled region that becomes focusable when it scrolls, so arrow keys scroll it.
