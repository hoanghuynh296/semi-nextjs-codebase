# Tabs

Switch between panels of content inside a card or dialog with underline tabs, icons and counts.

## When to use

- Sections of one object inside a card or dialog: Tổng quan / Hoạt động / Cài đặt.

## Use something else when

| Need | Use |
|---|---|
| 5+ sections of a page, or sections with icons (settings-like pages) | PillTabs |
| 2–4 top-level views of a discovery or reading page | TextTabs |
| 2–5 filter values shown in full, with counts | SegmentedControl |

## Import

```tsx
import { Tabs } from "@semi/ui";
```

## Examples

### Underline with panels

```tsx
"use client";

import { useState } from "react";
import { Tabs } from "@semi/ui";

export default function TabsUnderline() {
  const [tab, setTab] = useState<"overview" | "activity" | "settings">("overview");
  return (
    <Tabs
      label="Chi tiết máy in"
      value={tab}
      onChange={setTab}
      items={[
        { key: "overview", label: "Tổng quan", icon: "gauge", content: <p className="text-ui text-body">Nhiệt độ, tiến độ và camera.</p> },
        { key: "activity", label: "Hoạt động", count: 12, content: <p className="text-ui text-body">12 sự kiện trong 24 giờ qua.</p> },
        { key: "settings", label: "Cài đặt", icon: "settings", content: <p className="text-ui text-body">Tên, nhóm và quyền truy cập.</p> },
      ]}
    />
  );
}
```
