# Tabs

Switch between panels of content inside a page or card: underline (default) or segmented, with icons and counts.

## When to use

- Sections of one object: Tổng quan / Hoạt động / Cài đặt.
- A segmented period switch that changes a panel (variant="segmented").

## Use something else when

| Need | Use |
|---|---|
| Sibling pages of an area | PageTabsTitle |
| Filter a list (no panels) | Pills |

## Import

```tsx
import { Tabs } from "@semi/ui";
```

## Examples

### Underline with panels

```tsx
"use client";

import { useState } from "react";
import { Tabs } from "@semi/ui";

export default function TabsUnderline() {
  const [tab, setTab] = useState<"overview" | "activity" | "settings">("overview");
  return (
    <Tabs
      label="Chi tiết máy in"
      value={tab}
      onChange={setTab}
      items={[
        { key: "overview", label: "Tổng quan", icon: "gauge", content: <p className="text-ui text-body">Nhiệt độ, tiến độ và camera.</p> },
        { key: "activity", label: "Hoạt động", count: 12, content: <p className="text-ui text-body">12 sự kiện trong 24 giờ qua.</p> },
        { key: "settings", label: "Cài đặt", icon: "settings", content: <p className="text-ui text-body">Tên, nhóm và quyền truy cập.</p> },
      ]}
    />
  );
}
```

### Segmented

```tsx
"use client";

import { useState } from "react";
import { Tabs } from "@semi/ui";

export default function TabsSegmented() {
  const [range, setRange] = useState<"day" | "week" | "month">("week");
  return (
    <Tabs
      variant="segmented"
      label="Khoảng thời gian"
      value={range}
      onChange={setRange}
      items={[
        { key: "day", label: "Ngày" },
        { key: "week", label: "Tuần" },
        { key: "month", label: "Tháng" },
      ]}
    />
  );
}
```

## API

### Tabs

| Prop | Type | Default | Description |
|---|---|---|---|
| `items` * | `TabItem<T>[]` |  |  |
| `value` * | `T` |  |  |
| `onChange` * | `(key: T) => void` |  |  |
| `variant` | `'underline' \| 'segmented'` | `"underline"` | underline = section tabs inside a card or page · segmented = compact switch inside a toolbar. |
| `label` | `string` |  | Accessible name of the tab list. |
| `className` | `string` |  |  |
| `panelClassName` | `string` | `"pt-4"` |  |

## Accessibility

- tablist / tab / tabpanel; ←/→, Home, End move; the panel is linked to its tab.
