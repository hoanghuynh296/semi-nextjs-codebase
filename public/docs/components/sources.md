# Sources

Where an answer came from: Citation marks inside the text (numbered, linked) and a Sources list under the answer that opens to the pages.

## When to use

- Answers built from search or documents (RAG); every claim that came from a page.

## Import

```tsx
import { Sources, Citation, type Source } from "@semi/ui";
```

## Examples

### Answer with citations

```tsx
import { AssistantMessage, Citation, Sources, type Source } from "@semi/ui";

const SOURCES: Source[] = [
  { title: "Hướng dẫn in PETG", href: "https://example.com/petg-guide", description: "Nhiệt độ, quạt và bàn nhiệt" },
  { title: "Bảng thông số vật liệu", href: "https://docs.example.com/materials" },
  { title: "Diễn đàn: PETG bị kéo sợi", href: "https://forum.example.com/t/petg-stringing" },
];

export default function SourcesAnswer() {
  return (
    <div className="max-w-xl">
      <AssistantMessage actions={<Sources sources={SOURCES} />}>
        In PETG ở 230–250°C<Citation n={1} source={SOURCES[0]} />, bàn nhiệt 70–80°C<Citation n={2} source={SOURCES[1]} />. Kéo sợi thường giảm khi tăng rút
        nhựa lên 1–2 mm<Citation n={3} source={SOURCES[2]} />.
      </AssistantMessage>
    </div>
  );
}
```

## API

### Sources

“3 nguồn” under an answer, opening to the numbered list of pages it used (numbers match its `Citation`s).

| Prop | Type | Default | Description |
|---|---|---|---|
| `sources` * | `Source[]` |  |  |
| `defaultOpen` | `boolean` | `false` |  |
| `className` | `string` |  |  |

### Citation

A numbered citation inside answer text, linking to its source; hover or focus shows the title.

| Prop | Type | Default | Description |
|---|---|---|---|
| `n` * | `number` |  |  |
| `source` * | `Source` |  |  |

## Accessibility

- Citations are links named “Nguồn 2: title”; the list is a disclosure with an ordered list of external links (new tab).
