# Kbd

A key or a shortcut (⌘ K, Ctrl Enter) as key caps, for menus, tooltips, the command palette and help text.

## When to use

- Show the shortcut of an action next to it.

## Import

```tsx
import { Kbd } from "@semi/ui";
```

## Examples

### Keys and shortcuts

```tsx
import { Kbd } from "@semi/ui";

export default function KbdBasic() {
  return (
    <p className="flex flex-wrap items-center gap-2 text-ui text-body">
      Mở bảng lệnh <Kbd keys={["⌘", "K"]} /> · Gửi <Kbd keys={["Ctrl", "Enter"]} /> · Đóng <Kbd>Esc</Kbd>
    </p>
  );
}
```

## API

### Kbd

| Prop | Type | Default | Description |
|---|---|---|---|
| `keys` | `string[]` |  | Several keys of one shortcut: ["⌘", "K"] renders two key caps. |
| `children` | `React.ReactNode` |  | One key when `keys` is not given. |
| `className` | `string` |  |  |

## Accessibility

- Rendered as <kbd>; screen readers read the key names.
