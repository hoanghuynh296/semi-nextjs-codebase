# Reasoning

The model's reasoning above its answer: open while it streams, folded to “Đã suy luận trong N giây” when done, reopenable.

## When to use

- Models that expose thinking / reasoning text; show it before the AssistantMessage body.

## Use something else when

| Need | Use |
|---|---|
| A wait with no text yet | ChatThinking |

## Import

```tsx
import { Reasoning } from "@semi/ui";
```

## Examples

### Streaming, then folded

```tsx
"use client";

import { useEffect, useState } from "react";
import { AssistantMessage, Button, Reasoning } from "@semi/ui";

const STEPS = ["Người dùng hỏi về nhiệt độ in PETG.", "Nhà sản xuất khuyên 230–250°C cho đầu phun 0,4 mm.", "Bàn nhiệt 70–80°C để bám tốt mà không bị dính chặt.", "Nên giảm quạt làm mát để lớp dính nhau hơn."];

export default function ReasoningStreaming() {
  const [shown, setShown] = useState(STEPS.length);
  const busy = shown < STEPS.length;
  useEffect(() => {
    if (!busy) return;
    const id = setTimeout(() => setShown((n) => n + 1), 700);
    return () => clearTimeout(id);
  }, [busy, shown]);
  return (
    <div className="flex flex-col gap-3 max-w-xl">
      <Reasoning busy={busy} duration={4}>
        {STEPS.slice(0, shown).join("\n")}
      </Reasoning>
      {!busy && <AssistantMessage>In PETG ở 240°C, bàn nhiệt 75°C và quạt khoảng 30–50%.</AssistantMessage>}
      <div>
        <Button size="sm" variant="secondary" icon="refresh" onClick={() => setShown(0)}>
          Chạy lại
        </Button>
      </div>
    </div>
  );
}
```

## API

### Reasoning

The model's reasoning above its answer. Open while `busy` (the text streams in), folded to “Đã suy luận trong 12
giây” once it is done; people can open it again. A toggle by the user wins over the automatic open / close.

| Prop | Type | Default | Description |
|---|---|---|---|
| `busy` | `boolean` | `false` | The model is still reasoning. |
| `duration` | `number` |  | Seconds it took, shown once done. |
| `defaultOpen` | `boolean` |  | Start open (default: open only while busy). |
| `className` | `string` |  |  |
| `children` * | `React.ReactNode` |  |  |

## Accessibility

- A disclosure button (aria-expanded); the reasoning text is not a live region, so screen readers hear the answer, not every reasoning token.

## Notes

- Pass busy while reasoning streams; once a person toggles it, Reasoning stops opening and closing by itself.
