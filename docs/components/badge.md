# Badge

A read-only status or tag in a tone (10% fill, 20% border, theme-safe text), with an optional dot or icon.

## When to use

- Status of a row or card (Đã thanh toán, Lỗi), a plan or role tag.

## Use something else when

| Need | Use |
|---|---|
| Something clickable | Chip |
| A count next to a title | COUNT_PILL |

## Import

```tsx
import { Badge } from "@semi/ui";
```

## Examples

```tsx
import { Badge } from "@semi/ui";

        Nháp
      </Badge>
    </div>
  );
}
```

## API

### Badge

Standard Bento Tag/Badge primitive with dual-theme tonal matching.
Uses 10% alpha fill + 20% alpha border + high-contrast text adapted for dark and light modes.

| Prop | Type | Default | Description |
|---|---|---|---|
| `tone` | `SemanticTone` | `"gray"` | Chromatic tone matching the theme. Defaults to "gray". |
| `icon` | `IconName` |  | Optional leading icon from the Semi standard registry. |
| `dot` | `boolean` |  | Optional leading status dot in the tone's color. |
| `children` * | `React.ReactNode` |  |  |
| `className` | `string` | `""` |  |
| `size` | `'sm' \| 'md'` | `"md"` |  |

## Accessibility

- Text, not colour alone, carries the meaning; it never wraps.
