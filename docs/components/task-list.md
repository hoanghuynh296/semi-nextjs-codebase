# Task list

The agent's plan: steps with a status mark (chưa làm, đang làm, xong, lỗi, bỏ qua), an optional line under each, and a progress count.

## When to use

- Multi-step agent work (plans, migrations, onboarding jobs) people watch progress on.

## Use something else when

| Need | Use |
|---|---|
| Steps of a form | sections of the form |
| One running bar | Progress |

## Import

```tsx
import { TaskList, type TaskStep, type TaskStatus } from "@semi/ui";
```

## Examples

### Plan in progress

```tsx
import { TaskList } from "@semi/ui";

export default function TaskListPlan() {
  return (
    <TaskList
      className="max-w-md"
      title="In 20 giá đỡ cho đơn #1042"
      steps={[
        { label: "Kiểm tra tệp mô hình", status: "done" },
        { label: "Chọn máy in còn trống", status: "done", detail: "X1 Carbon 03, PETG đen" },
        { label: "Cắt lớp và ước lượng thời gian", status: "running" },
        { label: "Đặt lịch in", status: "pending" },
        { label: "Gửi báo giá cho khách", status: "skipped", detail: "Khách đã thanh toán trước" },
      ]}
    />
  );
}
```

## API

### TaskList

The agent's plan: steps with their status and a progress count. The running step is marked aria-current.

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` | `React.ReactNode` |  |  |
| `steps` * | `TaskStep[]` |  |  |
| `className` | `string` |  |  |

## Accessibility

- An ordered list; each step's status is also text (visually hidden); the running step has aria-current="step".
