# Button group

Joins related buttons into one segmented control: shared borders, outer corners only (‹ Hôm nay ›, Lưu | ▾).

## When to use

- Previous / today / next; a primary action with its overflow menu; zoom − / +.

## Use something else when

| Need | Use |
|---|---|
| Choose one value | ToggleGroup or Pills |

## Import

```tsx
import { ButtonGroup } from "@semi/ui";
```

## Examples

### Navigation and split button

```tsx
import { Button, ButtonGroup, Menu } from "@semi/ui";

export default function ButtonGroupBasic() {
  return (
    <div className="flex flex-wrap items-center gap-3">
      <ButtonGroup label="Điều hướng ngày">
        <Button iconOnly icon="back" aria-label="Ngày trước" />
        <Button>Hôm nay</Button>
        <Button iconOnly icon="chevron" aria-label="Ngày sau" />
      </ButtonGroup>
      <ButtonGroup label="Lưu">
        <Button variant="primary" icon="check">
          Lưu
        </Button>
        <Menu
          label="Tuỳ chọn lưu"
          items={[
            { label: "Lưu bản nháp", icon: "fileText", onSelect: () => undefined },
            { label: "Lưu và in", icon: "printer", onSelect: () => undefined },
          ]}
        />
      </ButtonGroup>
    </div>
  );
}
```

## API

### ButtonGroup

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` |  | Accessible name of the group ("Điều hướng ngày"). |
| `orientation` | `'horizontal' \| 'vertical'` | `"horizontal"` |  |
| `className` | `string` |  |  |
| `children` * | `React.ReactNode` |  | Button elements (Button, or anything styled with BTN_*). |

## Accessibility

- role="group" with a label; each button keeps its own name.
