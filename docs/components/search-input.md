# Search input

The toolbar search: an icon button that opens into a field (clear button, h-control); it collapses again when empty and focus leaves. SubpageToolbar includes one.

## When to use

- Filter the list or grid on the current page.

## Use something else when

| Need | Use |
|---|---|
| Search inside a form | Field + Input with icon="search" |

## Import

```tsx
import { SearchInput } from "@semi/ui";
```

## Examples

### Basic

```tsx
"use client";

import { useState } from "react";
import { SearchInput } from "@semi/ui";

export default function SearchInputBasic() {
  const [q, setQ] = useState("");
  return <SearchInput value={q} onChange={setQ} placeholder="Tìm máy in…" className="w-64" />;
}
```

- The icon button and the field are labelled by label (default: the placeholder); Escape clears and collapses it.
