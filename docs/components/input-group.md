# Input group

An input with fixed parts around it: a prefix (https://), a unit (kg, ₫), an icon or a small button (copy, show password).

## When to use

- Money and units, URLs and domains, a copy or reveal button inside the field.

## Use something else when

| Need | Use |
|---|---|
| Just an icon | Input with icon |

## Import

```tsx
import { InputGroup } from "@semi/ui";
```

## Examples

### Prefix, unit and button

```tsx
"use client";

import { useState } from "react";
import { Button, Field, Input, InputGroup } from "@semi/ui";

export default function InputGroupAddons() {
  const [show, setShow] = useState(false);
  return (
    <div className="grid gap-4 max-w-md">
      <Field label="Website">
        <InputGroup start="https://">
          <Input placeholder="3dnoobs.vn" />
        </InputGroup>
      </Field>
      <Field label="Giá bán">
        <InputGroup end="₫">
          <Input defaultValue="250.000" className="tabular-nums" />
        </InputGroup>
      </Field>
      <Field label="Mật khẩu Wi-Fi máy in">
        <InputGroup end={<Button size="sm" variant="ghost" iconOnly icon={show ? "eyeOff" : "eye"} aria-label={show ? "Ẩn" : "Hiện"} onClick={() => setShow((v) => !v)} />}>
          <Input type={show ? "text" : "password"} defaultValue="noobs-2026" />
        </InputGroup>
      </Field>
    </div>
  );
}
```

## API

### InputGroup

| Prop | Type | Default | Description |
|---|---|---|---|
| `start` | `React.ReactNode` |  | Before the input: text ("https://"), an <Icon />, a small Button. |
| `end` | `React.ReactNode` |  | After the input: a unit ("kg"), a Button (copy, show password). |
| `className` | `string` |  |  |
| `children` * | `React.ReactNode` |  | One Input (or Textarea / NumberInput). |

## Accessibility

- The Input inside keeps its label from Field; buttons in the group need their own aria-label.
