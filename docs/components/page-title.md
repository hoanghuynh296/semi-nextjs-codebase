# Page title

PageTitle is the display title of a page (text only), with the page's own action on its row (`actions`). PageTabsTitle is kept as a deprecated alias for 2–4 sibling tabs — new screens use TextTabs.

## When to use

- The first line of every page (PageTitle).
- A list page's title row: the title and the page's action (one primary or secondary, plus RefreshButton) above a StickyContextBar (PageTitle actions).

## Use something else when

| Need | Use |
|---|---|
| 2–4 top-level views as the page heading | TextTabs |
| 5+ sections of a page, or sections with icons | PillTabs |
| 2–5 filter values shown in full, with counts | SegmentedControl |
| Tabs inside a card or panel | Tabs |
| The top row of a detail or settings page (a Breadcrumb and one action) | MinimalHeader |

## Import

```tsx
import { PageTitle, PageTabsTitle } from "@semi/ui";
```

## Examples

### PageTitle

```tsx
import { PageTitle } from "@semi/ui";

export default function PageTitleBasic() {
  return <PageTitle title="Máy in" />;
}
```

### With the page's action

```tsx
"use client";

import { Button, PageTitle, RefreshButton, toast } from "@semi/ui";

export default function PageTitleActions() {
  // a list page's title row: the page's one action on the right; below sm it wraps under the title
  return (
    <PageTitle
      title="Yêu cầu mua"
      actions={
        <>
          <RefreshButton onRefresh={() => new Promise((r) => setTimeout(r, 600))} />
          <Button variant="primary" icon="plus" onClick={() => toast({ title: "Tạo yêu cầu" })}>
            Tạo yêu cầu
          </Button>
        </>
      }
    />
  );
}
```

### PageTabsTitle

```tsx
"use client";

import { useState } from "react";
import { PageTabsTitle } from "@semi/ui";

export default function PageTabsTitleBasic() {
  const [view, setView] = useState<"printers" | "jobs">("printers");
  return (
    <PageTabsTitle
      value={view}
      onChange={setView}
      tabs={[
        { key: "printers", label: "Máy in" },
        { key: "jobs", label: "Job in" },
      ]}
    />
  );
}
```

## API

### PageTitle

The page's display heading (its `h1`). With `actions`, the title row of a list page: the title on the left, the
page's action on the right; below `sm` the actions wrap onto their own row under the title.

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` * | `React.ReactNode` |  |  |
| `actions` | `React.ReactNode` |  | The page's own action at the right end of the title row: one `<Button variant="primary">` (or `inverse`) with an icon and text, optionally a `RefreshButton` before it. More actions go in a ⋯ `Menu` as the last item. Below `sm` they wrap under the title. Leave it out on a page whose `SubpageToolbar` carries the actions. |
| `className` | `string` | `""` |  |

### PageTabsTitle

Underline display tabs used when a view groups 2–4 sibling sub-pages (e.g. "Máy in / Job in", "Sản phẩm / Danh mục").

| Prop | Type | Default | Description |
|---|---|---|---|
| `tabs` * | `PageTabOption<T>[]` |  |  |
| `value` * | `T` |  |  |
| `onChange` * | `(key: T) => void` |  |  |
| `ariaLabel` | `string` |  |  |
| `className` | `string` | `""` |  |

## Accessibility

- PageTitle is the page h1; its actions follow it in the reading and tab order. PageTabsTitle is a tablist with arrow-key navigation.

## Notes

- No subtitle under the title. Title-row actions are one primary (or secondary) with icon and text, optionally a RefreshButton before it; more actions go in a ⋯ Menu. Filters never go on the title row: they belong in the StickyContextBar or SubpageToolbar under it.
- Below sm the actions wrap onto their own row under the title.
- A page whose SubpageToolbar carries the actions leaves `actions` out.
