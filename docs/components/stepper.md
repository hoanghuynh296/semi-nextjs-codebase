# Stepper

− value + for a small count (quantities, copies, seats) in a workspace panel or a card: one tap per step, a unit after the value, min and max.

## When to use

- A small whole number people nudge rather than type: tấn per line, copies, guests, 1–99.
- Inside a WorkspaceSection or a line card of a request.

## Use something else when

| Need | Use |
|---|---|
| A number people type (price, weight with decimals, a large count) | NumberInput |
| A value on a continuous range | Slider |

## Import

```tsx
import { Stepper } from "@semi/ui";
```

## Examples

### With a unit

```tsx
import { useState } from "react";
import { Stepper } from "@semi/ui";

export default function StepperBasic() {
  const [tons, setTons] = useState(12);
  return (
    <div className="max-w-xs">
      <Stepper label="số tấn tiêu đen" unit="tấn" min={1} value={tons} onChange={setTons} />
    </div>
  );
}
```

### Limits, step, disabled

```tsx
import { useState } from "react";
import { Stepper } from "@semi/ui";

export default function StepperLimits() {
  const [boxes, setBoxes] = useState(50);
  return (
    <div className="max-w-xs flex flex-col gap-3">
      <Stepper label="số thùng" unit="thùng" min={0} max={200} step={10} value={boxes} onChange={setBoxes} />
      <Stepper label="số bản in" value={1} onChange={() => undefined} disabled />
    </div>
  );
}
```

## API

### Stepper

− value + for small counts (quantities, copies, seats). The value is a `spinbutton`: ↑ / → add `step`, ↓ / ← take
it away, Page Up / Page Down move ten steps, Home / End go to `min` / `max`. The − + buttons are for pointer and
touch (out of the Tab order: the keys do the same). Free typing of large numbers is `NumberInput`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` * | `number` |  |  |
| `onChange` * | `(value: number) => void` |  |  |
| `min` | `number` | `0` |  |
| `max` | `number` | `99` |  |
| `step` | `number` | `1` |  |
| `label` * | `string` |  | What is counted, lower case ("số tấn tiêu đen"): names the value and the buttons ("Giảm số tấn tiêu đen"). |
| `unit` | `string` |  | Shown after the value and read with it ("12 tấn"). |
| `disabled` | `boolean` | `false` |  |
| `className` | `string` |  |  |

## Accessibility

- The value is a spinbutton (aria-valuenow / min / max, aria-valuetext with the unit) named by label: ↑ / → and ↓ / ← step, Page Up / Page Down move ten steps, Home / End go to min / max.
- The − + buttons are named (“Giảm …”, “Tăng …”) and left out of the Tab order: the keys do the same, so Tab reaches one stop per stepper.
