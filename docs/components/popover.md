# Popover

A small non-modal panel under its trigger for interactive content: a quick form, filters, a picker.

## When to use

- Quick edits without leaving the page (rename, set a limit), compact filter forms.

## Use something else when

| Need | Use |
|---|---|
| A list of actions | Menu |
| A focused multi-step task | Modal |
| A read-only preview on hover | HoverCard |
| A one-line hint | Tooltip |

## Import

```tsx
import { Popover } from "@semi/ui";
```

## Examples

### Quick edit

```tsx
"use client";

import { useState } from "react";
import { Button, Field, Input, Popover } from "@semi/ui";

export default function PopoverQuickEdit() {
  const [open, setOpen] = useState(false);
  const [name, setName] = useState("X1 Carbon 03");
  const [draft, setDraft] = useState(name);
  return (
    <div className="flex items-center gap-3">
      <span className="text-ui font-medium text-contrast">{name}</span>
      <Popover
        label="Đổi tên máy in"
        open={open}
        onOpenChange={(o) => {
          setOpen(o);
          if (o) setDraft(name);
        }}
        trigger={<Button size="sm" icon="edit">Đổi tên</Button>}
      >
        <form
          className="space-y-3"
          onSubmit={(e) => {
            e.preventDefault();
            setName(draft);
            setOpen(false);
          }}
        >
          <Field label="Tên máy in">
            <Input value={draft} onChange={(e) => setDraft(e.target.value)} />
          </Field>
          <div className="flex justify-end gap-2">
            <Button size="sm" onClick={() => setOpen(false)}>
              Huỷ
            </Button>
            <Button size="sm" variant="primary" type="submit">
              Lưu
            </Button>
          </div>
        </form>
      </Popover>
    </div>
  );
}
```

## API

### Popover

A non-modal dialog under its trigger. Focus moves into it; Escape, a click outside or tabbing out closes it, and
Escape returns focus to the trigger. Controlled with `open` + `onOpenChange`, or on its own.

| Prop | Type | Default | Description |
|---|---|---|---|
| `trigger` * | `ReactElement<unknown, string \| JSXElementConstructor<any>>` |  | The element that toggles it (usually a Button). |
| `label` * | `string` |  | Accessible name of the panel. |
| `align` | `'left' \| 'right' \| 'center'` | `"left"` |  |
| `width` | `number` | `280` | Minimum width in px (it grows with its content up to the viewport). |
| `open` | `boolean` |  |  |
| `onOpenChange` | `(open: boolean) => void` |  |  |
| `className` | `string` |  |  |
| `children` * | `React.ReactNode` |  |  |

## Accessibility

- A labelled dialog: focus moves in, Escape closes and returns focus to the trigger, clicking outside or tabbing out closes it.
