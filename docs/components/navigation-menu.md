# Navigation menu

Top navigation of a website or landing page: links, and items that open a panel of links with descriptions. Below md it becomes one menu button with a sheet.

## When to use

- Marketing sites, storefronts, docs headers.

## Use something else when

| Need | Use |
|---|---|
| Navigation of an app with many pages | AppShell |
| Commands of a tool (Tệp, Sửa) | Menubar |

## Import

```tsx
import { NavigationMenu, type NavigationItem } from "@semi/ui";
```

## Examples

### Site header

```tsx
import { NavigationMenu } from "@semi/ui";

export default function NavigationMenuSite() {
  return (
    <div className="flex items-center justify-between rounded-card border border-line bg-panel px-3 py-2">
      <span className="text-ui font-semibold text-contrast">3D Noobs</span>
      <NavigationMenu
        label="Điều hướng chính"
        current="/pricing"
        items={[
          {
            label: "Sản phẩm",
            links: [
              { label: "In theo yêu cầu", href: "/print", description: "Gửi file, nhận bản in trong 48 giờ", icon: "printer" },
              { label: "Vật liệu", href: "/materials", description: "PLA, PETG, TPU và nhựa kỹ thuật", icon: "box" },
              { label: "Studio", href: "/studio", description: "Thiết kế và lát cắt ngay trên web", icon: "sparkles" },
            ],
          },
          { label: "Bảng giá", href: "/pricing" },
          { label: "Liên hệ", href: "/contact" },
        ]}
      />
    </div>
  );
}
```

## API

### NavigationMenu

Disclosure navigation (buttons with aria-expanded, not an ARIA menu): Enter / Space / ↓ open a panel, Escape closes
it and returns focus, a click outside closes it; the current page link gets aria-current.

| Prop | Type | Default | Description |
|---|---|---|---|
| `items` * | `NavigationItem[]` |  |  |
| `label` * | `string` |  | Accessible name of the nav ("Điều hướng chính"). |
| `current` | `string` |  | href of the current page (marked with aria-current="page"). |
| `className` | `string` |  |  |

## Accessibility

- A nav landmark with disclosure buttons (aria-expanded), not an ARIA menu: Tab moves through links, Escape closes a panel and returns focus; the current page link has aria-current.
