# Tooltip

A short label on hover or focus, mostly for icon-only buttons.

## When to use

- Name an icon-only control; add a short hint to a truncated value.

## Use something else when

| Need | Use |
|---|---|
| Information people must read | visible text or an Alert |

## Import

```tsx
import { Tooltip } from "@semi/ui";
```

## Examples

### On an icon button

```tsx
import { Button, Tooltip } from "@semi/ui";

export default function TooltipIconButton() {
  return (
    <div className="flex gap-2">
      <Tooltip content="Đồng bộ lại dữ liệu">
        <Button iconOnly icon="refresh" aria-label="Làm mới" />
      </Tooltip>
      <Tooltip content="Tải báo cáo" side="bottom">
        <Button iconOnly icon="download" aria-label="Tải báo cáo" />
      </Tooltip>
    </div>
  );
}
```

## API

### Tooltip

Short hint for an icon-only control (one line, no interactive content). The trigger keeps its own aria-label;
the tooltip is linked with aria-describedby. Touch screens show nothing: never put essential text in a tooltip.

| Prop | Type | Default | Description |
|---|---|---|---|
| `content` * | `React.ReactNode` |  |  |
| `children` * | `ReactElement<unknown, string \| JSXElementConstructor<any>>` |  |  |
| `side` | `'bottom' \| 'top'` | `"top"` |  |

## Accessibility

- Shown on focus too, linked with aria-describedby; never the only place of essential information.
