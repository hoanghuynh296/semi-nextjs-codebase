# View switch

List ↔ grid and an optional density toggle, as small icon toggles at the end of the filter row (FilterChipRow trailing).

## When to use

- A collection people browse both as rows and as cards (products, files, suppliers).
- A dense list where some people want more rows on screen (density).

## Use something else when

| Need | Use |
|---|---|
| Switching between different data (orders vs. returns) | TextTabs or Pills |
| A table ↔ chart switch of one data set | Chart's table view |

## Import

```tsx
import { ViewSwitch } from "@semi/ui";
```

## Examples

### View and density

```tsx
"use client";

import { useState } from "react";
import { ViewSwitch, type ViewDensity, type ViewMode } from "@semi/ui";

export default function ViewSwitchDefault() {
  const [view, setView] = useState<ViewMode>("grid");
  const [density, setDensity] = useState<ViewDensity>("comfortable");
  return (
    <div className="flex items-center gap-4">
      <ViewSwitch view={view} onViewChange={setView} density={density} onDensityChange={setDensity} />
      <span className="text-label text-muted">
        {view === "grid" ? "Lưới" : "Danh sách"} · {density === "compact" ? "Gọn" : "Thoáng"}
      </span>
    </div>
  );
}
```

## API

### ViewSwitch

Two toggle buttons (list, grid; aria-pressed) and an optional density toggle. Put it in FilterChipRow's `trailing`;
keep the choice in the URL (`?view=grid`) or per person (localStorage) as the page needs.

| Prop | Type | Default | Description |
|---|---|---|---|
| `view` * | `'grid' \| 'list'` |  |  |
| `onViewChange` * | `(view: ViewMode) => void` |  |  |
| `density` | `'comfortable' \| 'compact'` |  | Shows the density toggle when given with `onDensityChange`. |
| `onDensityChange` | `(density: ViewDensity) => void` |  |  |
| `className` | `string` |  |  |

## Accessibility

- A group named “Kiểu xem” of toggle buttons (aria-pressed), each with an aria-label and a title.
- The density button is pressed while the view is compact.

## Notes

- Keep the view in the URL (?view=grid, replace, not push) when people share it, or per person (localStorage) when it is a taste.
- On phones it moves into FilterPanel's children or the settings button of PhoneFilterBar.
