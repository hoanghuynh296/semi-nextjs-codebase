# Pagination

Page numbers with previous / next for long tables. For card lists prefer auto-loading with “Xem thêm”.

## When to use

- Server-paged tables and reports.

## Use something else when

| Need | Use |
|---|---|
| A feed or card grid | auto-load near the end + a “Xem thêm” Button |

## Import

```tsx
import { Pagination, pageWindow } from "@semi/ui";
```

## Examples

### Basic

```tsx
"use client";

import { useState } from "react";
import { Pagination } from "@semi/ui";

export default function PaginationBasic() {
  const [page, setPage] = useState(3);
  return <Pagination page={page} pages={12} onChange={setPage} />;
}
```

## API

### Pagination

| Prop | Type | Default | Description |
|---|---|---|---|
| `page` * | `number` |  | Current page, 1-based. |
| `pages` * | `number` |  |  |
| `onChange` * | `(page: number) => void` |  |  |
| `className` | `string` | `""` |  |

## Accessibility

- A nav landmark; the current page has aria-current="page"; arrows are labelled.
