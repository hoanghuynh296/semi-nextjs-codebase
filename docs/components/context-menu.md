# Context menu

The menu of an area opened at the pointer: right-click, long-press on touch, or the Menu key / Shift+F10 when the area has focus.

## When to use

- Power-user shortcuts on canvases, file grids and rows, when the same actions also exist in a visible Menu or toolbar.

## Use something else when

| Need | Use |
|---|---|
| The only way to reach an action | Menu (visible trigger) |

## Import

```tsx
import { ContextMenu } from "@semi/ui";
```

## Examples

### On a file card

```tsx
import { ContextMenu, IconTile, toast } from "@semi/ui";

export default function ContextMenuFile() {
  return (
    <ContextMenu
      label="Thao tác tệp"
      items={[
        { label: "Mở", icon: "external", onSelect: () => toast({ title: "Mở tệp" }) },
        { label: "Nhân bản", icon: "copy", shortcut: "⌘D", onSelect: () => toast({ title: "Đã nhân bản", tone: "success" }) },
        { label: "Xoá", icon: "trash", danger: true, separator: true, onSelect: () => toast({ title: "Đã xoá", tone: "danger" }) },
      ]}
    >
      <div className="flex w-64 items-center gap-3 rounded-card border border-line bg-field p-3">
        <IconTile name="fileCode" tone="sky" />
        <div className="min-w-0">
          <div className="text-ui font-medium text-contrast truncate">vo-hop-dieu-khien.gcode</div>
          <div className="text-caption text-muted">Chuột phải (hoặc giữ) để mở menu</div>
        </div>
      </div>
    </ContextMenu>
  );
}
```

## API

### ContextMenu

The menu of an area opened at the pointer: right-click, long-press on touch, or the Menu key / Shift+F10 when the
area has focus. Use for power-user shortcuts that also exist elsewhere (a row's Menu, a toolbar button).

| Prop | Type | Default | Description |
|---|---|---|---|
| `items` * | `MenuItem[]` |  |  |
| `label` | `string` |  | Accessible name of the menu. |
| `className` | `string` |  |  |
| `children` * | `React.ReactNode` |  | The area that opens the menu (it becomes focusable). |

## Accessibility

- The area is focusable; Menu key / Shift+F10 open the menu, which behaves like Menu (arrows, Escape returns focus).
