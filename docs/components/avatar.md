# Avatar

A person or team: their image, or initials on a tone picked from the name.

## When to use

- Owners, assignees, customers in rows and cards.

## Import

```tsx
import { Avatar } from "@semi/ui";
```

## Examples

### Sizes

```tsx
import { Avatar } from "@semi/ui";

export default function AvatarSizes() {
  return (
    <div className="flex items-center gap-3">
      <Avatar name="Hoàng Huỳnh" size="lg" />
      <Avatar name="Semi Team" />
      <Avatar name="Lan" size="sm" />
    </div>
  );
}
```
