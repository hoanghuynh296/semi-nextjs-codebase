# Checkbox

A native checkbox with label and description, checked fill in the accent, and an indeterminate state for “select all”.

## When to use

- Opt in to something in a form (accept terms, include archived).
- Select rows; “select all” with indeterminate.

## Use something else when

| Need | Use |
|---|---|
| A setting that applies at once | Switch |
| Exactly one option of a few | RadioGroup |

## Import

```tsx
import { Checkbox } from "@semi/ui";
```

## Examples

### With description

```tsx
"use client";

import { useState } from "react";
import { Checkbox } from "@semi/ui";

export default function CheckboxBasic() {
  const [auto, setAuto] = useState(true);
  return <Checkbox checked={auto} onChange={setAuto} label="Tự động in khi rảnh" description="Máy nhận job tiếp theo trong hàng đợi." />;
}
```

### Indeterminate and disabled

```tsx
"use client";

import { useState } from "react";
import { Checkbox } from "@semi/ui";

export default function CheckboxStates() {
  const [all, setAll] = useState(false);
  return (
    <div className="flex flex-col gap-3">
      <Checkbox checked={all} indeterminate={!all} onChange={setAll} label="Chọn tất cả" />
      <Checkbox checked={false} onChange={() => undefined} label="Không khả dụng" disabled />
    </div>
  );
}
```
