# Menu

The action menu behind a trigger: a ⋯ (or your own Button) with items that have an icon, a description line, a shortcut or hint, a check, a spinner, a link, a reason when disabled, and group headings. Danger items always go last after a divider; hidden items (and empty groups) leave the list; below sm it opens as a bottom sheet.

## When to use

- Secondary actions of a row, card or page (Đổi tên, Nhân bản, Xoá): G2, G4.
- The ⋯ overflow of a toolbar, a bulk bar or a detail header (G2, G9, G12).

## Use something else when

| Need | Use |
|---|---|
| One or two visible actions | Button |
| Other ways to start the main action (manual, import) | SplitButton |
| Actions on a card in a grid | CardActions |
| Pick a value | CustomSelect |

## Import

```tsx
import { Menu, type MenuItem } from "@semi/ui";
```

## Examples

### Row actions

```tsx
"use client";

import { Menu, toast } from "@semi/ui";

export default function MenuRowActions() {
  return (
    <Menu
      label="Thao tác máy in"
      items={[
        { label: "Đổi tên", icon: "edit", onSelect: () => toast({ title: "Đổi tên" }) },
        { label: "Nhân bản", icon: "copy", onSelect: () => toast({ title: "Đã nhân bản", tone: "success" }) },
        { label: "Tạm dừng", icon: "pause", onSelect: () => undefined, disabled: true },
        { label: "Xoá", icon: "trash", danger: true, separator: true, onSelect: () => toast({ title: "Không xoá được", description: "Máy đang in.", tone: "danger" }) },
      ]}
    />
  );
}
```

### Groups, states and danger last

Xoá is first in the code and shows last; the hidden item is not listed; Gửi qua Zalo says why it is off.

```tsx
"use client";

import { useState } from "react";
import { Button, Menu, toast } from "@semi/ui";

export default function MenuGrouped() {
  const [compact, setCompact] = useState(false);
  const [exporting, setExporting] = useState(false);
  const exportFile = () => {
    setExporting(true);
    setTimeout(() => (setExporting(false), toast({ title: "Đã xuất 128 dòng", tone: "success" })), 1200);
  };
  return (
    <Menu
      label="Thao tác với danh sách khách hàng"
      trigger={<Button icon="more">Thao tác</Button>}
      items={[
        // danger is listed first here on purpose: Menu always shows it last, after a divider (G5)
        { label: "Xoá danh sách", icon: "trash", danger: true, onSelect: () => toast({ title: "Đã xoá", tone: "danger" }) },
        { label: "Xuất Excel", icon: "download", group: "Xuất", description: "128 dòng đang lọc", loading: exporting, onSelect: exportFile },
        { label: "In danh sách", icon: "printer", group: "Xuất", shortcut: "⌘P", onSelect: () => window.print() },
        { label: "Gửi qua Zalo", icon: "send", group: "Xuất", disabled: "Chưa kết nối Zalo OA", onSelect: () => undefined },
        { label: "Chỉ quản trị viên", icon: "lock", group: "Xuất", hidden: true, onSelect: () => undefined },
        { label: "Hiển thị gọn", group: "Xem", checked: compact, onSelect: () => setCompact((v) => !v) },
        { label: "Mở trang cài đặt", icon: "settings", group: "Xem", href: "#settings" },
      ]}
    />
  );
}
```

## API

### Menu

Action menu behind a trigger button (row / card overflow actions). ↑/↓ move, Enter / Space pick, Escape closes and
returns focus. Default trigger: icon-only "more" button; pass `trigger` (an element) to use your own.

| Prop | Type | Default | Description |
|---|---|---|---|
| `items` * | `MenuItem[]` |  | The actions. Danger items are listed last, hidden ones left out (see MenuItem). |
| `header` | `React.ReactNode` |  | Text above the items that is not an item (an account menu's name and role). It sits outside the `role="menu"` list, so arrows and type-ahead skip it. |
| `label` | `string` |  | Accessible name of the default trigger. |
| `align` | `'left' \| 'right'` | `"right"` |  |
| `trigger` | `ReactElement<unknown, string \| JSXElementConstructor<any>>` |  |  |
| `sheet` | `boolean` | `true` | Below `sm` the list opens as a bottom sheet over a backdrop (P6, since 0.39). `false` keeps the anchored dropdown on phones too. |

## Accessibility

- WAI-ARIA menu button: Enter / Space / ↓ open on the first item, ↑ on the last; arrows, Home, End move; a letter jumps to the next item starting with it; Escape closes and returns focus to the trigger; Tab closes.
- A check makes the item menuitemcheckbox with aria-checked (with radio: menuitemradio, and the menu opens on the checked item); a disabled item with a reason stays reachable (aria-disabled) and its reason is its description; a group is role=group named by its heading.
