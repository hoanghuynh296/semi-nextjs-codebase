# Menu

The overflow menu of a row or card: a ⋯ trigger (or your own) with items, icons, separators and a danger item last.

## When to use

- Secondary actions of a row or card (Đổi tên, Nhân bản, Xoá).

## Use something else when

| Need | Use |
|---|---|
| One or two visible actions | Button |
| Pick a value | CustomSelect |

## Import

```tsx
import { Menu } from "@semi/ui";
```

## Examples

### Row actions

```tsx
"use client";

import { Menu, toast } from "@semi/ui";

export default function MenuRowActions() {
  return (
    <Menu
      label="Thao tác máy in"
      items={[
        { label: "Đổi tên", icon: "edit", onSelect: () => toast({ title: "Đổi tên" }) },
        { label: "Nhân bản", icon: "copy", onSelect: () => toast({ title: "Đã nhân bản", tone: "success" }) },
        { label: "Tạm dừng", icon: "pause", onSelect: () => undefined, disabled: true },
        { label: "Xoá", icon: "trash", danger: true, separator: true, onSelect: () => toast({ title: "Không xoá được", description: "Máy đang in.", tone: "danger" }) },
      ]}
    />
  );
}
```

## API

### Menu

Action menu behind a trigger button (row / card overflow actions). ↑/↓ move, Enter / Space pick, Escape closes and
returns focus. Default trigger: icon-only "more" button; pass `trigger` (an element) to use your own.

| Prop | Type | Default | Description |
|---|---|---|---|
| `items` * | `MenuItem[]` |  |  |
| `label` | `string` |  | Accessible name of the default trigger. |
| `align` | `'left' \| 'right'` | `"right"` |  |
| `trigger` | `ReactElement<unknown, string \| JSXElementConstructor<any>>` |  |  |

## Accessibility

- role="menu": Enter / Space / ↓ open, arrows move, Escape closes and returns focus to the trigger.
