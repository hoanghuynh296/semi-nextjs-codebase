# Split button

The main action and a ▾ that opens a Menu of the other ways to do the same job (Thêm khách hàng | ▾ Nhập từ file, Tìm trong Data Hub). One filled button in total; below sm one button opens the whole list, the main action first.

## When to use

- Two or more ways to start one job (type it in, import a file, copy from another system): G1.
- A detail header or side panel action with variants (Gửi hỏi giá | ▾ Gửi từ mẫu, Gọi điện).

## Use something else when

| Need | Use |
|---|---|
| Unrelated secondary actions (export, settings, print) | Menu (⋯) |
| A toggle or the steps of one control (view mode, ‹ Hôm nay ›) | ButtonGroup |
| One action with no alternatives | Button |

## Import

```tsx
import { SplitButton } from "@semi/ui";
```

## Examples

### In a toolbar

Narrow the window below sm: one button opens Thêm khách hàng and its alternatives.

```tsx
"use client";

import { Button, SearchInput, SplitButton, toast } from "@semi/ui";

// G1: one way to start one job. The other ways to add a customer live under the ▾, not as toolbar buttons.
export default function SplitButtonToolbar() {
  return (
    <div className="flex items-center gap-2 flex-wrap">
      <SearchInput value="" onChange={() => undefined} placeholder="Tìm khách hàng" className="flex-1 min-w-48" />
      <Button iconOnly icon="download" aria-label="Xuất Excel" />
      <SplitButton
        label="Thêm khách hàng"
        icon="plus"
        onClick={() => toast({ title: "Mở biểu mẫu thêm khách hàng" })}
        menuLabel="Cách thêm khác"
        items={[
          { label: "Nhập từ file", icon: "upload", description: "Excel hoặc CSV", onSelect: () => toast({ title: "Chọn file" }) },
          { label: "Tìm trong Data Hub", icon: "search", onSelect: () => toast({ title: "Mở Data Hub" }) },
        ]}
      />
    </div>
  );
}
```

### Subtle, loading

```tsx
"use client";

import { useState } from "react";
import { SplitButton, toast } from "@semi/ui";

// A secondary SplitButton (a detail header that already has its primary), with a running main action.
export default function SplitButtonSecondary() {
  const [busy, setBusy] = useState(false);
  return (
    <SplitButton
      variant="subtle"
      label="Mở trong IDE"
      icon="code"
      loading={busy}
      onClick={() => {
        setBusy(true);
        setTimeout(() => setBusy(false), 1200);
      }}
      menuLabel="Mở bằng cách khác"
      items={[
        { label: "Mở Terminal", icon: "terminal", onSelect: () => toast({ title: "Mở Terminal" }) },
        { label: "Mở trong Finder", icon: "folder", onSelect: () => toast({ title: "Mở Finder" }) },
      ]}
    />
  );
}
```

## API

### SplitButton

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` * | `string` |  | The main action ("Thêm khách hàng"). |
| `icon` | `IconName` |  |  |
| `onClick` * | `() => void` |  |  |
| `items` * | `MenuItem[]` |  | The other ways to do the same job (manual, import, copy from another system). Danger items go last. |
| `menuLabel` | `string` |  | Accessible name of the ▾ button and of its menu (default "Thao tác khác"). |
| `variant` | `'subtle' \| 'surface' \| 'inverse' \| 'primary' \| 'secondary'` | `"primary"` | `primary` (brand) for the view's one main action (G7), `inverse` for the main action of a card or a list title row, `subtle` elsewhere; `secondary` is the brand secondary. |
| `size` | `'sm' \| 'md'` | `"md"` |  |
| `loading` | `boolean` | `false` | The main action is running: spinner and no clicks on the main half; the ▾ stays usable. |
| `disabled` | `boolean` | `false` | Disables both halves. |
| `collapseOnPhone` | `boolean` | `true` | Below `sm`, show one button (the icon, or the label with ▾) that opens a menu with the main action first. |
| `className` | `string` |  |  |

## Accessibility

- A group named by the main label; the ▾ is a menu button (aria-haspopup=menu, aria-expanded) with its own name (menuLabel); the menu follows Menu's keyboard.
