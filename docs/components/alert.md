# Alert

A message that stays on the page: info, success, warning, danger, with a title, an action and an optional dismiss.

## When to use

- State the user must see while working (firmware update, low material, failed print).

## Use something else when

| Need | Use |
|---|---|
| A passing confirmation | toast() |
| Ask before acting | confirmDialog() |

## Import

```tsx
import { Alert } from "@semi/ui";
```

## Examples

### Tones

```tsx
import { Alert, Button } from "@semi/ui";

export default function AlertTones() {
  return (
    <div className="grid gap-3 @2xl:grid-cols-2">
      <Alert tone="info" title="Bản cập nhật mới">
        Firmware 1.08 đã sẵn sàng cho 3 máy.
      </Alert>
      <Alert tone="success" title="Đã kết nối">
        Máy X1 Carbon đang online.
      </Alert>
      <Alert tone="warning" title="Sắp hết nhựa" action={<Button size="sm">Đặt thêm</Button>}>
        Cuộn PLA đen còn khoảng 80 g.
      </Alert>
      <Alert tone="danger" title="In thất bại">
        Đầu phun bị tắc ở lớp 132.
      </Alert>
    </div>
  );
}
```

### Dismissible

```tsx
"use client";

import { useState } from "react";
import { Alert, Button } from "@semi/ui";

export default function AlertDismiss() {
  const [open, setOpen] = useState(true);
  return open ? (
    <Alert tone="warning" title="Mất kết nối camera" onDismiss={() => setOpen(false)}>
      Ảnh sẽ cập nhật lại khi máy online.
    </Alert>
  ) : (
    <Button size="sm" onClick={() => setOpen(true)}>
      Hiện lại
    </Button>
  );
}
```

## API

### Alert

Callout inside a page or form (docs/DESIGN_SYSTEM.md §3b): tinted surface, tone icon, optional action / dismiss.

| Prop | Type | Default | Description |
|---|---|---|---|
| `tone` | `'danger' \| 'info' \| 'success' \| 'warning'` | `"info"` |  |
| `title` | `React.ReactNode` |  |  |
| `children` | `React.ReactNode` |  |  |
| `icon` | `IconName` |  | Override the tone's icon. |
| `action` | `React.ReactNode` |  | A button or link shown under the text. |
| `onDismiss` | `() => void` |  |  |
| `className` | `string` |  |  |

## Accessibility

- role="status" (role="alert" for danger); the dismiss button is labelled.
