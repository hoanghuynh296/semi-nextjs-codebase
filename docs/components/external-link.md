# External link

A link to another site: opens a new tab on desktop and the external browser inside a mobile WebView, with an external-link icon.

## When to use

- Any link that leaves the app (docs, GitHub, a payment page).

## Use something else when

| Need | Use |
|---|---|
| A page inside the app | next/link |
| An action | Button |

## Import

```tsx
import { ExternalLink } from "@semi/ui";
```

## Examples

### Basic

```tsx
import { ExternalLink } from "@semi/ui";

export default function ExternalLinkBasic() {
  return (
    <p className="text-ui text-body">
      Xem hướng dẫn chi tiết tại <ExternalLink href="https://example.com/guide">trang tài liệu</ExternalLink>.
    </p>
  );
}
```
