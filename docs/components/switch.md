# Switch

An on / off toggle for settings that apply immediately.

## When to use

- Settings that take effect at once (notifications, dark sync, auto-print).
- A switch on a card whose title names it: pass aria-labelledby (the title's id) or aria-label instead of a visible label.

## Use something else when

| Need | Use |
|---|---|
| A choice saved with a form | Checkbox |

## Import

```tsx
import { Switch } from "@semi/ui";
```

## Examples

### Basic and small

```tsx
"use client";

import { useState } from "react";
import { Switch } from "@semi/ui";

export default function SwitchBasic() {
  const [notify, setNotify] = useState(true);
  const [quiet, setQuiet] = useState(false);
  return (
    <div className="flex flex-col gap-3">
      <Switch checked={notify} onChange={setNotify} label="Thông báo khi in xong" description="Gửi qua ứng dụng và email." />
      <Switch checked={quiet} onChange={setQuiet} size="sm" label="Chế độ im lặng" />
    </div>
  );
}
```

### Named by a card title

No visible label: aria-labelledby points at the card title.

```tsx
"use client";

import { useState } from "react";
import { Badge, Card, Switch } from "@semi/ui";

const RULES = [
  { id: "maint", name: "Nhắc bảo trì", detail: "Mỗi 200 giờ in" },
  { id: "night", name: "Tắt máy ban đêm", detail: "23:00, khi không có job" },
];

export default function SwitchCardHeader() {
  const [on, setOn] = useState<Record<string, boolean>>({ maint: true, night: false });
  return (
    <div className="grid gap-3 @lg:grid-cols-2">
      {RULES.map((r) => (
        <Card key={r.id} className="p-4 space-y-2">
          <div className="flex items-center justify-between gap-3">
            <span id={`rule-${r.id}`} className="text-ui font-semibold text-contrast">
              {r.name}
            </span>
            <Switch checked={on[r.id]} onChange={(v) => setOn({ ...on, [r.id]: v })} aria-labelledby={`rule-${r.id}`} />
          </div>
          <p className="text-label text-muted">{r.detail}</p>
          <Badge tone={on[r.id] ? "emerald" : "gray"}>{on[r.id] ? "Đang bật" : "Đang tắt"}</Badge>
        </Card>
      ))}
    </div>
  );
}
```

## API

### Switch

| Prop | Type | Default | Description |
|---|---|---|---|
| `checked` * | `boolean` |  |  |
| `onChange` * | `(checked: boolean) => void` |  |  |
| `label` | `React.ReactNode` |  | Visible label; it names the switch. |
| `description` | `React.ReactNode` |  |  |
| `disabled` | `boolean` | `false` |  |
| `size` | `'sm' \| 'md'` | `"md"` | Visible size only: on touch screens both sizes get a 44 × 44 px hit area. |
| `id` | `string` |  |  |
| `className` | `string` |  |  |
| `aria-label` | `string` |  | Name for screen readers when the switch has no visible `label` ("Bật automation Nhắc bảo trì"). `label` wins. |
| `aria-labelledby` | `string` |  | Id of the element that names the switch when its text is elsewhere (a card header). `label` wins. |

## Accessibility

- role="switch" with aria-checked; Space toggles; label and description are linked.
- Without a visible label give aria-label or aria-labelledby (label wins); in development a switch with no name logs a warning.
- On touch screens (any coarse pointer) the hit area is 44 × 44 px around the track; the visible size and layout do not change.
