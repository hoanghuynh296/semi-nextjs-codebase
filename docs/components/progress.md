# Progress

A determinate bar with value, or an indeterminate one when the end is unknown; tones for success and danger.

## When to use

- Print progress, upload, storage used.

## Use something else when

| Need | Use |
|---|---|
| Content still loading | Skeleton |

## Import

```tsx
import { Progress } from "@semi/ui";
```

## Examples

### Values and tones

```tsx
import { Progress } from "@semi/ui";

export default function ProgressBasic() {
  return (
    <div className="grid gap-4 @2xl:grid-cols-2">
      <Progress label="Tiến độ in" value={64} showValue />
      <Progress label="Dung lượng" value={92} tone="danger" showValue />
      <Progress label="Đang xử lý" />
      <Progress label="Đã tải" value={30} tone="success" size="sm" />
    </div>
  );
}
```

## API

### Progress

Determinate or indeterminate progress bar (uploads, quotas, print progress).

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `number` |  | Omit for an indeterminate bar. |
| `max` | `number` | `100` |  |
| `tone` | `'danger' \| 'info' \| 'success' \| 'warning' \| 'accent'` | `"accent"` |  |
| `label` | `React.ReactNode` |  | Visible label above the bar (also its accessible name). |
| `showValue` | `boolean` | `false` |  |
| `size` | `'sm' \| 'md'` | `"md"` |  |
| `className` | `string` |  |  |

## Accessibility

- role="progressbar" with aria-valuenow / max; the label names it.
