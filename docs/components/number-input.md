# Number input

NumberInput: numbers with a touch keypad (NumPadPopup) on phones and tablets, plain typing elsewhere. Never type="number".

## When to use

- Quantities, temperatures, prices, percentages.

## Use something else when

| Need | Use |
|---|---|
| A range picked by dragging | a slider (coming in a later release) |

## Import

```tsx
import { NumberInput, NumPadPopup, FIELD_INPUT } from "@semi/ui";
```

## Examples

### With unit

```tsx
"use client";

import { useState } from "react";
import { FIELD_INPUT, Field, NumberInput } from "@semi/ui";

export default function NumberInputBasic() {
  const [temp, setTemp] = useState("220");
  return (
    <Field label="Nhiệt độ đầu phun" hint="Trên màn hình cảm ứng mở bàn phím số.">
      <NumberInput className={FIELD_INPUT} value={temp} onChange={(e) => setTemp(e.target.value)} unit="°C" integer numpadLabel="Nhiệt độ" />
    </Field>
  );
}
```

## API

### NumberInput

| Prop | Type | Default | Description |
|---|---|---|---|
| `ref` | `React.Ref<HTMLInputElement>` |  |  |
| `numpadLabel` | `string` |  | Title shown on the numpad (defaults to aria-label / placeholder). |
| `unit` | `string` |  | Unit shown next to the value on the numpad. |
| `integer` | `boolean` |  | Whole numbers only (no decimal key). |

### NumPadPopup

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` * | `string` |  |  |
| `unit` | `string` |  |  |
| `initial` * | `string` |  |  |
| `integer` | `boolean` |  | whole numbers only |
| `allowPercent` | `boolean` |  | allow a trailing % (value like "15%") |
| `onCommit` * | `(value: string) => void` |  |  |
| `onClose` * | `() => void` |  |  |

## Accessibility

- inputMode="decimal" or numeric; the keypad is a dialog with focus trap and Escape.
