# Minimal header

The top row of a detail or settings page inside AppShell: where the page sits on the left (a Breadcrumb), one text link and one primary action on the right. The page's own heading follows it.

## When to use

- A detail page (one order, one customer) or a settings page reached from a list.
- A page with one main action and at most one secondary link.

## Use something else when

| Need | Use |
|---|---|
| A list page: its title, create action and refresh | PageTitle actions (then StickyContextBar or SubpageToolbar) |
| A stand-alone tool app (no sidebar) | AppHeader |
| Several actions of a record | MinimalHeader primary + Menu in the page |

## Import

```tsx
import { MinimalHeader } from "@semi/ui";
```

## Examples

### Detail page

```tsx
"use client";

import { Breadcrumb, Button, MinimalHeader } from "@semi/ui";

export default function MinimalHeaderDetail() {
  return (
    <MinimalHeader
      left={<Breadcrumb items={[{ label: "Đơn hàng", href: "#" }, { label: "DH-1042" }]} />}
      link={<a href="#" className="text-strong hover:underline">Xem lịch sử</a>}
      primary={
        <Button variant="primary" icon="check">
          Xác nhận đơn
        </Button>
      }
    />
  );
}
```

## API

### MinimalHeader

| Prop | Type | Default | Description |
|---|---|---|---|
| `left` * | `React.ReactNode` |  | Left side: a `Breadcrumb` (usual) or a short title. Truncates, never wraps the row. |
| `link` | `React.ReactNode` |  | One text link (a `Link` / `ExternalLink`: "Hướng dẫn", "Xem lịch sử"). Hidden below `sm`, so do not put the only way to something here. |
| `primary` | `React.ReactNode` |  | One primary action (`<Button variant="primary">`); a second action belongs in the page or a `Menu`. |
| `className` | `string` |  |  |

## Accessibility

- A header element; the Breadcrumb is its own nav landmark.
- The link is hidden below sm: never make it the only way to reach something.

## Notes

- One primary (Button variant="primary") at most: a second filled button on the screen breaks the one-primary rule (§4b, §4c).
- It sits above the page heading (PageTitle or TextTabs), inside AppShell's content container.
