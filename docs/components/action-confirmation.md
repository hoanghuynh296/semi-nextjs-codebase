# Action confirmation

An action the agent wants to take that needs a person's OK (send, delete, pay, run a command): what it will do, then Cho phép / Từ chối; the outcome replaces the buttons once decided.

## When to use

- Human-in-the-loop: any agent action that is outward-facing, costs money or cannot be undone.

## Use something else when

| Need | Use |
|---|---|
| Confirming a person's own action | confirmDialog |

## Import

```tsx
import { ActionConfirmation } from "@semi/ui";
```

## Examples

### Approve or reject

```tsx
"use client";

import { useState } from "react";
import { ActionConfirmation } from "@semi/ui";

export default function ActionConfirmationApprove() {
  const [mail, setMail] = useState<"pending" | "approved" | "rejected">("pending");
  const [wipe, setWipe] = useState<"pending" | "approved" | "rejected">("pending");
  return (
    <div className="flex flex-col gap-3 max-w-xl">
      <ActionConfirmation title="Gửi email báo giá cho 3 khách hàng?" icon="send" approveLabel="Gửi 3 email" state={mail} onApprove={() => setMail("approved")} onReject={() => setMail("rejected")}>
        an@example.com, binh@example.com, chi@example.com
      </ActionConfirmation>
      <ActionConfirmation title="Xoá 128 tệp G-code cũ hơn 90 ngày?" icon="trash" danger approveLabel="Xoá 128 tệp" state={wipe} onApprove={() => setWipe("approved")} onReject={() => setWipe("rejected")}>
        Không thể khôi phục sau khi xoá.
      </ActionConfirmation>
    </div>
  );
}
```

## API

### ActionConfirmation

An action the agent wants to take that needs a person's OK (send an email, delete files, spend money). Shows what
it will do, then Cho phép / Từ chối; once decided, the outcome replaces the buttons so the log stays readable.

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` * | `React.ReactNode` |  | What it will do, as a question or a short line (“Gửi email cho 3 khách hàng?”). |
| `icon` | `IconName` | `"shield"` |  |
| `state` | `'pending' \| 'approved' \| 'rejected'` | `"pending"` |  |
| `danger` | `boolean` | `false` | The action cannot be undone: the approve button is red. |
| `approveLabel` | `string` |  |  |
| `rejectLabel` | `string` |  |  |
| `onApprove` * | `() => void` |  |  |
| `onReject` * | `() => void` |  |  |
| `className` | `string` |  |  |
| `children` | `React.ReactNode` |  | The details (recipients, files, the command). |

## Accessibility

- A labelled group; buttons say what they do (approveLabel “Gửi 3 email”); danger makes the approve button red for actions that cannot be undone.

## Notes

- Keep it in the conversation after the decision (state) so the log shows who allowed what.
