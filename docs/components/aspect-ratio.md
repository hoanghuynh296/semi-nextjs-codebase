# Aspect ratio

Keeps media at a fixed ratio while its width follows the layout (images, video, maps, 3D previews).

## When to use

- Thumbnails and media that must not jump while loading.

## Import

```tsx
import { AspectRatio } from "@semi/ui";
```

## Examples

### 16:9 and square

```tsx
import { AspectRatio } from "@semi/ui";

export default function AspectRatioBasic() {
  return (
    <div className="grid gap-3 grid-cols-2 max-w-md">
      <AspectRatio className="rounded-card border border-line bg-field">
        <div className="flex h-full items-center justify-center text-label text-muted">16 : 9</div>
      </AspectRatio>
      <AspectRatio ratio={1} className="rounded-card border border-line bg-field">
        <div className="flex h-full items-center justify-center text-label text-muted">1 : 1</div>
      </AspectRatio>
    </div>
  );
}
```

## API

### AspectRatio

| Prop | Type | Default | Description |
|---|---|---|---|
| `ratio` | `number` | `16 / 9` | Width / height: 16 / 9 (default), 4 / 3, 1, 3 / 4. |
| `className` | `string` |  | Radius / border / background of the frame. |
| `children` * | `React.ReactNode` |  | Usually an <img> or <video> with "w-full h-full object-cover". |

## Accessibility

- A plain wrapper; give the image its own alt text.
