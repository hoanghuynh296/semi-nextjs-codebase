# Resizable panels

Panels side by side or stacked with handles to resize them (an editor beside a preview, a list beside details). Sizes are percentages and can be remembered.

## When to use

- Tools where people tune the space between two or three areas.

## Use something else when

| Need | Use |
|---|---|
| A collapsible tool panel beside a canvas | SidePanel |
| A temporary detail view | Drawer |

## Import

```tsx
import { ResizablePanels } from "@semi/ui";
```

## Examples

### List and details

```tsx
import { ResizablePanels } from "@semi/ui";

export default function ResizableEditor() {
  return (
    <ResizablePanels defaultSizes={[35, 65]} className="h-64">
      <div className="p-4 text-label text-muted">Danh sách đơn</div>
      <div className="p-4 text-label text-muted">Chi tiết đơn đang chọn</div>
    </ResizablePanels>
  );
}
```

### Stacked, three panels

```tsx
import { ResizablePanels } from "@semi/ui";

export default function ResizableVertical() {
  return (
    <ResizablePanels direction="vertical" defaultSizes={[50, 30, 20]} className="h-80">
      <div className="p-4 text-label text-muted">Khung xem 3D</div>
      <div className="p-4 text-label text-muted">Lớp</div>
      <div className="p-4 text-label text-muted">Nhật ký</div>
    </ResizablePanels>
  );
}
```

## API

### ResizablePanels

| Prop | Type | Default | Description |
|---|---|---|---|
| `direction` | `'horizontal' \| 'vertical'` | `"horizontal"` |  |
| `defaultSizes` | `number[]` |  | Starting sizes in %, one per panel (default: equal). |
| `minSize` | `number` | `15` | Smallest size of a panel in %. |
| `storageKey` | `string` |  | Remember the sizes in localStorage under this key. |
| `className` | `string` |  | Height for direction="vertical" (e.g. "h-96"). |
| `children` * | `React.ReactNode` |  | One child per panel (2 or more). |

## Accessibility

- Each handle is a focusable separator with aria-valuenow; ←/→ (↑/↓ when stacked) resize, Shift for bigger steps.
