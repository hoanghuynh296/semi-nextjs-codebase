# Date picker

A calendar popover for one date (YYYY-MM-DD), with min / max. Never type="date".

## When to use

- Schedule a job, filter by day, set a due date.

## Import

```tsx
import { DatePicker } from "@semi/ui";
```

## Examples

### Basic

```tsx
"use client";

import { useState } from "react";
import { DatePicker } from "@semi/ui";

export default function DatePickerBasic() {
  const [date, setDate] = useState("2026-11-01");
  return <DatePicker value={date} onChange={setDate} min="2026-10-01" ariaLabel="Ngày in" />;
}
```

## Accessibility

- Arrow keys move by day / week, Enter picks, Escape closes; give it an ariaLabel when there is no Field.
