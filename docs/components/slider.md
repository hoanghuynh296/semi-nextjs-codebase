# Slider

Pick a number in a range by dragging: one thumb, or two with range for a min–max pair.

## When to use

- Values where the position matters more than the exact number (volume, opacity, infill, price range filters).

## Use something else when

| Need | Use |
|---|---|
| An exact number | NumberInput |

## Import

```tsx
import { Slider } from "@semi/ui";
```

## Examples

### Single

```tsx
"use client";

import { useState } from "react";
import { Slider } from "@semi/ui";

export default function SliderSingle() {
  const [infill, setInfill] = useState(20);
  return <Slider label="Độ đặc (infill)" value={infill} onChange={setInfill} step={5} showValue format={(v) => `${v}%`} className="max-w-sm" />;
}
```

### Range

```tsx
"use client";

import { useState } from "react";
import { Slider } from "@semi/ui";

export default function SliderRange() {
  const [price, setPrice] = useState<[number, number]>([100, 600]);
  return (
    <Slider
      range
      label="Khoảng giá"
      value={price}
      onChange={setPrice}
      min={0}
      max={1000}
      step={50}
      showValue
      format={(v) => `${v}k ₫`}
      className="max-w-sm"
    />
  );
}
```

## API

### Slider

One or two thumbs (role="slider"): ←/↓ and →/↑ step, PageUp / PageDown jump 10 steps, Home / End go to the ends;
drag or click the track. `value` is a number, or [low, high] with `range`.

| Prop | Type | Default | Description |
|---|---|---|---|
| `min` | `number` |  |  |
| `max` | `number` |  |  |
| `step` | `number` |  |  |
| `label` * | `string` |  | Visible label above the track (also the accessible name). |
| `showValue` | `boolean` |  | Show the formatted value next to the label. |
| `format` | `(value: number) => string` |  | Text of a value (units, %): read by screen readers too (aria-valuetext). |
| `disabled` | `boolean` |  |  |
| `className` | `string` |  |  |
| `range` | `boolean` |  |  |
| `value` * | `number \| [number, number]` |  |  |
| `onChange` * | `(value: number) => void \| (value: [number, number]) => void` |  |  |

## Accessibility

- role="slider" per thumb with aria-valuenow / aria-valuetext (format): arrows step, PageUp / PageDown jump, Home / End go to the ends.
