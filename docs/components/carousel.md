# Carousel

Slides in a row that scroll by swipe, trackpad, arrow keys, buttons or dots (CSS scroll-snap, no library). Phones show one slide and a peek of the next.

## When to use

- Product photos, featured items, onboarding steps.

## Use something else when

| Need | Use |
|---|---|
| Content people must not miss | a grid or a list |
| Steps of a task | a form with sections |

## Import

```tsx
import { Carousel } from "@semi/ui";
```

## Examples

### Products, 3 per view

```tsx
import { AspectRatio, Card, Carousel } from "@semi/ui";

const ITEMS = ["Giá đỡ điện thoại", "Hộp đựng tai nghe", "Móc khoá logo", "Chậu cây mini", "Kệ sách nhỏ"];

export default function CarouselProducts() {
  return (
    <Carousel label="Sản phẩm nổi bật" perView={3}>
      {ITEMS.map((name, i) => (
        <Card key={name} className="p-3 space-y-2">
          <AspectRatio ratio={4 / 3} className="rounded-control bg-field">
            <div className="flex h-full items-center justify-center text-display font-semibold text-muted">{i + 1}</div>
          </AspectRatio>
          <div className="text-ui font-medium text-contrast">{name}</div>
          <div className="text-label text-muted tabular-nums">{(89 + i * 30).toLocaleString("vi-VN")}k ₫</div>
        </Card>
      ))}
    </Carousel>
  );
}
```

## API

### Carousel

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` * | `string` |  | Accessible name of the carousel ("Ảnh sản phẩm"). |
| `perView` | `2 \| 3 \| 4 \| 1` | `1` | Slides visible at once from sm up (phones always show one and a peek of the next). |
| `className` | `string` |  |  |
| `children` * | `React.ReactNode` |  | One child per slide. |

## Accessibility

- aria-roledescription="carousel" with a label; slides are labelled groups (“2 / 5”); the track is focusable and ←/→ move; no auto-play.
