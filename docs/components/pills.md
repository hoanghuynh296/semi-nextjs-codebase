# Pills (deprecated)

Deprecated in 1.0: use SegmentedControl for 2–5 filter values shown in full (with counts and a sliding raised-2 pill) or PillTabs for 5+ page sections with icons. Kept exported so existing screens continue to compile until migrated.

## When to use

- Legacy screens not yet migrated to SegmentedControl or PillTabs.

## Use something else when

| Need | Use |
|---|---|
| 2–5 filter values shown in full, with counts | SegmentedControl |
| 5+ sections of a page, or sections with icons | PillTabs |
| 2–4 top-level views of a discovery or reading page | TextTabs |
| Filters of a list | FilterChipRow |

## Import

```tsx
import { Pills } from "@semi/ui";
```

## Examples

### Status filter

```tsx
"use client";

import { useState } from "react";
import { Pills } from "@semi/ui";

export default function PillsBasic() {
  const [status, setStatus] = useState("all");
  return (
    <Pills
      value={status}
      onChange={setStatus}
      options={[
        { key: "all", label: "Tất cả" },
        { key: "printing", label: "Đang in" },
        { key: "idle", label: "Chờ lệnh" },
        { key: "error", label: "Lỗi" },
      ]}
    />
  );
}
```

## Accessibility

- Each option is a button with aria-pressed; Tab moves between options. SegmentedControl uses WAI-ARIA radiogroup / radio with arrow keys.
