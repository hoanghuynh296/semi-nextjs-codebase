# Pills

A single-choice filter of 2–5 options on one track (segmented look). The left side of a SubpageToolbar.

## When to use

- Filter a list by status or period: Tất cả / Đang in / Xong.
- Switch a small view mode with no panels.

## Use something else when

| Need | Use |
|---|---|
| Switch panels of content | Tabs |
| Many filters, several at once | Chip |
| Sibling pages | PageTabsTitle |

## Import

```tsx
import { Pills } from "@semi/ui";
```

## Examples

### Status filter

```tsx
"use client";

import { useState } from "react";
import { Pills } from "@semi/ui";

export default function PillsBasic() {
  const [status, setStatus] = useState("all");
  return (
    <Pills
      value={status}
      onChange={setStatus}
      options={[
        { key: "all", label: "Tất cả" },
        { key: "printing", label: "Đang in" },
        { key: "idle", label: "Chờ lệnh" },
        { key: "error", label: "Lỗi" },
      ]}
    />
  );
}
```
