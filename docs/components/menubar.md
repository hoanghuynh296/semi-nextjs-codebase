# Menubar

The menu bar of a desktop-style tool (Tệp · Sửa · Xem): menus that open from a bar and behave like Menu.

## When to use

- Editors and tool apps with many commands (3D, slicer, image tools), next to an AppHeader.

## Use something else when

| Need | Use |
|---|---|
| Page navigation | NavigationMenu or AppShell |
| A few actions | Buttons or one Menu |

## Import

```tsx
import { Menubar, type MenubarMenu } from "@semi/ui";
```

## Examples

### Editor menus

```tsx
import { Menubar, toast } from "@semi/ui";

const run = (title: string) => () => toast({ title });

export default function MenubarEditor() {
  return (
    <Menubar
      label="Lệnh của trình chỉnh sửa"
      menus={[
        {
          label: "Tệp",
          items: [
            { label: "Mở…", icon: "folderOpen", shortcut: "⌘O", onSelect: run("Mở tệp") },
            { label: "Lưu", icon: "check", shortcut: "⌘S", onSelect: run("Đã lưu") },
            { label: "Xuất G-code", icon: "download", separator: true, onSelect: run("Xuất G-code") },
          ],
        },
        {
          label: "Sửa",
          items: [
            { label: "Hoàn tác", shortcut: "⌘Z", onSelect: run("Hoàn tác") },
            { label: "Làm lại", shortcut: "⇧⌘Z", onSelect: run("Làm lại"), disabled: true },
          ],
        },
        {
          label: "Xem",
          items: [
            { label: "Vừa khung hình", icon: "focus", onSelect: run("Vừa khung hình") },
            { label: "Hiện lưới", icon: "grid", onSelect: run("Hiện lưới") },
          ],
        },
      ]}
    />
  );
}
```

## API

### Menubar

The menu bar of a desktop-style tool (Tệp · Sửa · Xem): ←/→ move between menus (and switch the open one), ↓ / Enter
open, the menus behave like Menu. For page navigation use NavigationMenu or AppShell instead.

| Prop | Type | Default | Description |
|---|---|---|---|
| `menus` * | `MenubarMenu[]` |  |  |
| `label` * | `string` |  |  |
| `className` | `string` |  |  |

## Accessibility

- role="menubar": ←/→ move between menus (and switch the open one), ↓ / Enter open, Escape closes and returns focus; one tab stop for the bar.
