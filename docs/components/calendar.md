# Calendar

A month grid to pick one day or a range (YYYY-MM-DD, weeks start on Monday). DatePicker shows it in a popover; place it inline for schedules and report filters.

## When to use

- Inline date selection on a page; picking a date range for a report.

## Use something else when

| Need | Use |
|---|---|
| A date field in a form | DatePicker |

## Import

```tsx
import { Calendar, isoDay, parseDay, type DayRange } from "@semi/ui";
```

## Examples

### One day

```tsx
"use client";

import { useState } from "react";
import { Calendar } from "@semi/ui";

export default function CalendarSingle() {
  const [day, setDay] = useState("2026-11-12");
  return <Calendar value={day} onChange={setDay} min="2026-11-01" />;
}
```

### Range

Click a start day, then an end day.

```tsx
"use client";

import { useState } from "react";
import { Calendar, type DayRange } from "@semi/ui";

export default function CalendarRange() {
  const [range, setRange] = useState<DayRange>({ start: "2026-11-03", end: "2026-11-09" });
  return (
    <div className="space-y-2">
      <Calendar mode="range" value={range} onChange={setRange} />
      <p className="text-label text-muted tabular-nums">
        {range.start ?? "…"} → {range.end ?? "…"}
      </p>
    </div>
  );
}
```

## API

### Calendar

A grid of days (role="grid"): arrows move by day / week, Home / End to the start / end of the week, PageUp /
PageDown by month (Shift: by year), Enter / Space pick. Only the focused day is in the tab order.

| Prop | Type | Default | Description |
|---|---|---|---|
| `min` | `string` |  | Earliest / latest selectable day ("YYYY-MM-DD"). |
| `max` | `string` |  |  |
| `autoFocus` | `boolean` |  | Move focus into the grid when it mounts (DatePicker does). |
| `className` | `string` |  |  |
| `mode` | `'single' \| 'range'` |  |  |
| `value` * | `string \| DayRange` |  |  |
| `onChange` * | `(value: string) => void \| (value: DayRange) => void` |  |  |

## Accessibility

- role="grid": arrows move by day / week, Home / End to the week's ends, PageUp / PageDown by month (Shift: year), Enter / Space pick; today has aria-current="date".
