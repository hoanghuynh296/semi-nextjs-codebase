# Confirm dialog

confirmDialog() asks one yes / no question and resolves to true or false. Mount ConfirmHost once in the root layout. Never window.confirm.

## When to use

- Before deleting, stopping a print or discarding changes.

## Use something else when

| Need | Use |
|---|---|
| A form or several fields | Modal |
| Undo instead of asking | toast() with an action |

## Import

```tsx
import { ConfirmHost, confirmDialog } from "@semi/ui";
```

## Examples

### Destructive confirmation

```tsx
"use client";

import { useState } from "react";
import { Button, confirmDialog } from "@semi/ui";

export default function ConfirmDanger() {
  const [result, setResult] = useState("");
  const remove = async () => {
    const ok = await confirmDialog({
      title: "Xoá bản in mẫu?",
      message: "Tệp G-code và dữ liệu lát cắt sẽ bị xoá vĩnh viễn.",
      confirmLabel: "Xoá",
      tone: "danger",
    });
    setResult(ok ? "Đã xoá" : "Đã huỷ");
  };
  return (
    <div className="flex items-center gap-3">
      <Button variant="danger" icon="trash" onClick={remove}>
        Xoá bản in
      </Button>
      {result && <span className="text-label text-muted">{result}</span>}
    </div>
  );
}
```

## API

### ConfirmHost

Mounted once in the root layout; renders the dialog opened by `confirmDialog()`.

No props of its own.

## Accessibility

- An alertdialog: focus starts on the safe button (Huỷ), Escape cancels.

## Notes

- <ConfirmHost /> goes once in the root layout (see Theme › Root layout); confirmDialog() works from any event handler.
