# Confirm dialog

confirmDialog() asks one yes / no question and resolves to true or false; confirmDelete({ name }) is the irreversible-action form (names the object, red Xoá). Mount ConfirmHost once in the root layout. Never window.confirm.

## When to use

- Before an irreversible action: delete, stop a print, discard changes. confirmDelete names the object.
- A reversible action does not ask: do it and offer toast.undo.

## Use something else when

| Need | Use |
|---|---|
| A form or several fields | Modal |
| Undo instead of asking (reversible actions) | toast.undo() |

## Import

```tsx
import { ConfirmHost, confirmDialog, confirmDelete } from "@semi/ui";
```

## Examples

### Destructive confirmation

```tsx
"use client";

import { useState } from "react";
import { Button, confirmDialog } from "@semi/ui";

export default function ConfirmDanger() {
  const [result, setResult] = useState("");
  const remove = async () => {
    const ok = await confirmDialog({
      title: "Xoá bản in mẫu?",
      message: "Tệp G-code và dữ liệu lát cắt sẽ bị xoá vĩnh viễn.",
      confirmLabel: "Xoá",
      tone: "danger",
    });
    setResult(ok ? "Đã xoá" : "Đã huỷ");
  };
  return (
    <div className="flex items-center gap-3">
      <Button variant="danger" icon="trash" onClick={remove}>
        Xoá bản in
      </Button>
      {result && <span className="text-label text-muted">{result}</span>}
    </div>
  );
}
```

### Irreversible delete

confirmDelete: the title names the object, the button is red and says Xoá.

```tsx
"use client";

import { Button, confirmDelete, toast } from "@semi/ui";

// An irreversible action: the dialog names the object, the button is red ("Xoá"), Huỷ is the safe default.
// Success is a toast afterwards, never a second dialog.
export default function ConfirmDeleteExample() {
  const remove = async () => {
    if (await confirmDelete({ name: "Máy in xưởng 3", message: "Lịch sử in của máy cũng bị xoá." })) toast.success("Đã xoá máy in");
  };
  return (
    <Button variant="danger" icon="trash" onClick={remove}>
      Xoá máy in
    </Button>
  );
}
```

## API

### ConfirmHost

Mounted once in the root layout; renders the dialog opened by `confirmDialog()`.

No props of its own.

## Accessibility

- An alertdialog: focus starts on the safe button (Huỷ) in a danger dialog and on the confirm button otherwise; Escape cancels.

## Notes

- <ConfirmHost /> goes once in the root layout (see Theme › Root layout); confirmDialog() works from any event handler.
- confirmDelete takes deleteTitle(name), deleteMessage and delete from the locale provider around ConfirmHost (English with locale={en}).
