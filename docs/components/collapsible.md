# Collapsible

One section that opens and closes under its trigger row (advanced options, details of a log line).

## When to use

- Hide rarely used options (“Tuỳ chọn khác”), long details.

## Use something else when

| Need | Use |
|---|---|
| Several sections, one open at a time | Accordion |

## Import

```tsx
import { Collapsible } from "@semi/ui";
```

## Examples

### Advanced options

```tsx
import { Collapsible, Field, Input } from "@semi/ui";

export default function CollapsibleBasic() {
  return (
    <Collapsible title="Tuỳ chọn khác" className="max-w-md">
      <div className="space-y-3">
        <Field label="Nhiệt độ bàn">
          <Input defaultValue="60 °C" />
        </Field>
        <Field label="Tốc độ quạt">
          <Input defaultValue="40%" />
        </Field>
      </div>
    </Collapsible>
  );
}
```

## Accessibility

- The trigger is a button with aria-expanded / aria-controls; hidden content is out of the tab order.
