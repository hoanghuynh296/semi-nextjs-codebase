# Hover card

A preview card while the pointer rests on, or focus is on, a link: a person, a product, an order.

## When to use

- Peek at a linked record without opening it.

## Use something else when

| Need | Use |
|---|---|
| Anything people must act on | Popover (click) |
| A one-line label | Tooltip |

## Import

```tsx
import { HoverCard } from "@semi/ui";
```

## Examples

### Person

```tsx
import { Avatar, Badge, HoverCard } from "@semi/ui";

export default function HoverCardUser() {
  return (
    <p className="text-ui text-body">
      Đơn được duyệt bởi{" "}
      <HoverCard
        trigger={
          <a href="#minh-anh" className="font-medium text-accent-fg underline-offset-2 hover:underline">
            Minh Anh
          </a>
        }
      >
        <div className="flex items-start gap-3">
          <Avatar name="Minh Anh" />
          <div className="space-y-1">
            <div className="text-ui font-semibold text-contrast">Minh Anh</div>
            <div className="text-label text-muted">Quản lý xưởng · Khu A</div>
            <Badge tone="emerald" dot size="sm">
              Đang trực
            </Badge>
          </div>
        </div>
      </HoverCard>
      .
    </p>
  );
}
```

## API

### HoverCard

A preview card while the pointer rests on (or keyboard focus is on) its trigger, usually a link. It adds detail
only: touch screens never show it, so the link must work without it.

| Prop | Type | Default | Description |
|---|---|---|---|
| `trigger` * | `ReactElement<unknown, string \| JSXElementConstructor<any>>` |  | A link or button; it keeps its own name and action. |
| `openDelay` | `number` | `400` |  |
| `closeDelay` | `number` | `150` |  |
| `width` | `number` | `260` |  |
| `className` | `string` |  |  |
| `children` * | `React.ReactNode` |  |  |

## Accessibility

- Opens on hover and keyboard focus, closes on Escape; touch screens never show it, so the link must work alone.
