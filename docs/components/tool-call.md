# Tool call

One tool the agent called: its name in words, a status badge (chờ, đang chạy, xong, lỗi, chờ duyệt), and on open the input and output (JSON formatted).

## When to use

- Agent runs and chats where the model calls functions, MCP tools or APIs.

## Use something else when

| Need | Use |
|---|---|
| A shell command and its output | Terminal |
| A list of planned steps | TaskList |

## Import

```tsx
import { ToolCall, type ToolCallStatus } from "@semi/ui";
```

## API

### ToolCall

One tool the agent called: a row with its name and status that opens to show the input (arguments) and the output.
Strings show as they are, anything else as formatted JSON; `error` shows in place of the output.

| Prop | Type | Default | Description |
|---|---|---|---|
| `name` * | `string` |  | The tool's id ("search_files"). |
| `title` | `React.ReactNode` |  | What it does in words ("Tìm tệp cấu hình"); the row shows it instead of the name. |
| `icon` | `IconName` | `"wrench"` |  |
| `status` * | `'pending' \| 'running' \| 'done' \| 'error' \| 'awaiting'` |  |  |
| `input` | `unknown` |  | Arguments: a string or any JSON value. |
| `output` | `unknown` |  | Result: a string or any JSON value. |
| `error` | `React.ReactNode` |  | Error message when status is "error". |
| `defaultOpen` | `boolean` | `false` |  |
| `className` | `string` |  |  |
| `children` | `React.ReactNode` |  | Anything else under the output (a preview, an ActionConfirmation). |

## Accessibility

- The row is a disclosure button; status is text in the badge, not colour only; an error is role="alert".

## Notes

- Give title in words (“Tìm máy in rảnh”); name (the tool id) shows inside.
- Put an ActionConfirmation inside (children) when the call waits for approval.
