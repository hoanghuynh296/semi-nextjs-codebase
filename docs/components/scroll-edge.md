# Scroll edge

A soft fade on the edge of a scrolling area where more content continues, like Apple's: only on that side, gone at the end of the scroll. Modal, Drawer and confirmDialog have it built in; SCROLL_EDGE + useScrollEdges give it to your own scroller on the panel surface. It is the one gradient Semi allows (C-022).

## When to use

- Your own fixed-height scroller on bg-panel (a terms box, a list in a popover) whose content can be longer than the box.
- Nothing to do in Modal, Drawer or confirmDialog: they already show it.

## Use something else when

| Need | Use |
|---|---|
| A scrolling list in a card, with edge lines and an optional scrollbar | ScrollArea |
| Columns past the edge of a table | DataTable (its 2px edge line) |

## Import

```tsx
import { useScrollEdges, SCROLL_EDGE } from "@semi/ui";
```

## Examples

### Terms in a fixed-height box

```tsx
"use client";

import { useRef } from "react";
import { SCROLL_EDGE, cn, useScrollEdges } from "@semi/ui";

/** Your own scrolling area on the panel surface: the hook says which edges continue, SCROLL_EDGE draws the fades. */
export default function ScrollEdgeTerms() {
  const ref = useRef<HTMLDivElement>(null);
  const edges = useScrollEdges(ref);
  return (
    <div className="relative max-w-md">
      <div
        ref={ref}
        role="region"
        aria-label="Điều khoản sử dụng"
        tabIndex={edges.scrolls ? 0 : undefined}
        className="h-48 overflow-y-auto overscroll-contain space-y-3 outline-none focus-visible:ring-2 focus-visible:ring-focus rounded-control"
      >
        {Array.from({ length: 12 }, (_, i) => (
          <p key={i} className="text-ui text-body">
            Điều {i + 1}. Người dùng chịu trách nhiệm về nội dung tải lên và đồng ý để hệ thống lưu bản sao trong 30 ngày.
          </p>
        ))}
      </div>
      <span aria-hidden className={cn(SCROLL_EDGE.top, edges.top ? "opacity-100" : "opacity-0")} />
      <span aria-hidden className={cn(SCROLL_EDGE.bottom, edges.bottom ? "opacity-100" : "opacity-0")} />
    </div>
  );
}
```

## API

### useScrollEdges

Which edges of a vertically scrolling element have more content past them, for the scroll edge effect
(`SCROLL_EDGE`): `top` once it is scrolled down, `bottom` until its end, both false when the content fits.
`scrolls` tells when to make the element keyboard focusable (`tabIndex={0}`). The element may mount after the
hook (a dialog that opens): it is picked up on the next render.

No props of its own.

## Accessibility

- The fades are aria-hidden and pointer-events-none: they never take a click or a tap.
- Make the scroller focusable while it scrolls (tabIndex={edges.scrolls ? 0 : undefined}) and name it, so arrow keys can scroll it.
- The fade is an opacity change in 150ms (transition-hover), with no transition under reduced motion.

## Notes

- Never copy SCROLL_EDGE's value: semi-lint's gradient rule lets only the constant itself through.
- The fade goes from the panel colour to transparent: use it on bg-panel (dialogs, drawers, the content card). The system overlay scrollbar stays as it is.
