# Select

CustomSelect: pick one value from a list, in a field, in a toolbar, inline in a row or bare. Never the native <select>.

## When to use

- One value from a short or medium list (printers, regions).
- A compact sort / group control in a toolbar (variant="toolbar").

## Use something else when

| Need | Use |
|---|---|
| A long list the user types into | CustomCombobox |
| 2–5 visible options | Pills or RadioGroup |

## Import

```tsx
import { CustomSelect } from "@semi/ui";
```

## Examples

### In a form

```tsx
"use client";

import { useState } from "react";
import { CustomSelect, Field } from "@semi/ui";

export default function SelectField() {
  const [printer, setPrinter] = useState("x1c");
  return (
    <Field label="Máy in">
      <CustomSelect
        variant="field"
        value={printer}
        onChange={setPrinter}
        options={[
          { value: "x1c", label: "Bambu Lab X1-Carbon" },
          { value: "p1s", label: "Bambu Lab P1S" },
          { value: "a1", label: "Bambu Lab A1 Mini" },
        ]}
      />
    </Field>
  );
}
```

### In a toolbar

```tsx
"use client";

import { useState } from "react";
import { CustomSelect } from "@semi/ui";

export default function SelectToolbar() {
  const [sort, setSort] = useState("recent");
  return (
    <CustomSelect
      variant="toolbar"
      aria-label="Sắp xếp"
      value={sort}
      onChange={setSort}
      options={[
        { value: "recent", label: "Mới nhất" },
        { value: "name", label: "Tên A–Z" },
        { value: "status", label: "Trạng thái" },
      ]}
    />
  );
}
```

## API

### CustomSelect

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` * | `string` |  |  |
| `onChange` * | `(val: string) => void` |  |  |
| `options` * | `CustomSelectOption[]` |  |  |
| `placeholder` | `string` |  |  |
| `className` | `string` | `""` |  |
| `align` | `'left' \| 'right'` | `"left"` | Which edge the option list lines up with (use "right" for a select at the right edge of the screen). |
| `iconsInList` | `boolean` | `false` | Show each option's icon in the list too (default: only on the button). |
| `iconOnly` | `boolean` | `false` | The button shows only the selected option's icon (its label becomes the tooltip), e.g. the AI profile logo. |
| `variant` | `'toolbar' \| 'field' \| 'inline' \| 'bare'` | `"toolbar"` | toolbar = h-control toolbar control (34px in Flat) · field = full-width form field · inline = bare text inside a row · bare = no trigger styling (the caller passes it in buttonClassName, e.g. the automation code chips) |
| `disabled` | `boolean` | `false` |  |
| `buttonClassName` | `string` | `""` | Extra classes on the button (e.g. a "modified value" colour). |
| `id` | `string` |  |  |
| `aria-label` | `string` |  |  |
| `title` | `string` |  |  |

## Accessibility

- A listbox button: Enter / Space / arrows open it, type-ahead jumps, Escape closes and returns focus.
