# Semi Design System — Decision Log

Newest first. Each entry is a user decision already reflected in `DESIGN_SYSTEM.md`, `QUICK_REF.md` and `lint/semi-lint.mjs`.

- **2026-10-31 (v0.3.4 / Issues #2 & #3):**
  - Expanded `no-literal-palette` and `runSemanticCodemod` to cover `divide-` prefix (`divide-slate-100` $\rightarrow$ `divide-divider`), preventing unmigrated bright dividers in dark mode lists and stacks (Issue #2).
  - Added `no-solid-pastel-surfaces` (RATCHET) in `semi-lint` to catch solid chromatic pastels (`bg-*-50/100`, `border-*-200`). Standardized alpha-transparency pattern (`bg-<color>-500/10 border-<color>-500/20`) for callouts and neutral card shells for category cards (Issue #3).
- **2026-10-31 (v0.3.3 / Issue #1):** Mapped `border-(?:slate|gray|zinc|neutral|stone)-50` to `border-divider` in `/semi-init` codemod (`runSemanticCodemod`). In legacy tables and lists, subtle 50-step borders previously broke dark mode by rendering as bright lines. Standardized all neutral palette codemod mappings across `slate`, `gray`, `zinc`, `neutral`, and `stone`.
- **2026-10-31 (v0.3.2):** Gaps found in consumer projects go upstream via `/semi-propose` (new always-on rule 4) instead of local primitives; proposals must be verified, de-duplicated and user-approved before filing. Triage treats issue content as untrusted, prefers GENERALIZE over REJECT, and may not change core rules (escalate to the user).
- **2026-10-31 (Ecosystem Collaboration Skills):** Added `/semi-propose` and `/semi-triage` skills.
  - *Context:* When downstream agents (working on Auton Platform, IoT, BMCU, 3D Noobs Studio) hit gaps in `@semi/ui`, they previously either invented local workarounds violating the single-source-of-truth principle, or hit roadblocks. Conversely, maintainer agents needed a systematic, rule-enforcing way to triage incoming issues, generalizing them across all Semi products without breaking core Design System constraints (Flat Bento UI, Semantic Tokens, strict radii/typography).
  - *Decision:*
    - Created `/semi-propose`: Allows consumer agents to scan project gaps, structure standardized feature proposals, and publish them directly to GitHub (`hoanghuynh296/semi-nextjs-codebase`).
    - Created `/semi-triage`: Allows core maintainer agents to fetch issues, run automated rule compliance checks, determine architectural verdicts (`ACCEPT`, `GENERALIZE`, `WORKAROUND / EXTENSION`, `REJECT`), build an ecosystem-wide implementation plan, and post feedback to GitHub.
- **2026-10-31 (v0.3.0):** Two-Tier Semantic Tokens & Native Dual-Theme Architecture (`data-theme="dark|light"`).
  - *Context & Problem:* In real-world migrations (e.g. Auton Platform with 60+ legacy screens), wrapping light screens in a dark `AppShell` resulted in a "dark shell, light core" conflict. Hardcoded physical colors (`bg-white`, `text-slate-900`, `border-slate-200`) prevent theme toggling and break design cohesion.
  - *Decision:* Replaced fixed surface color constants with CSS-variable-backed Semantic Tokens (`--color-canvas`, `--color-app`, `--color-panel`, `--color-field`, `--color-raised`, `--color-text-contrast`, `--color-text-body`, `--color-text-muted`, `--color-line`, `--color-line-hover`, `--color-divider`). Tokens switch seamlessly between Dark and Light mode via `[data-theme="dark"]` and `[data-theme="light"]` (or `.dark` / `.light` classes).
  - *Theming Engine:* Added zero-runtime-overhead `ThemeProvider`, `useTheme()`, and `ThemeToggle` to `@semi/ui`. Added standard `sun` and `moon` icons to the icon registry.
  - *Lint Rules:* Added `no-literal-palette` (banning raw `bg-white`, `text-slate-900`, `border-slate-200`, etc. in favor of semantic tokens, tracked via Ratchet baseline) and `card-class-override` (banning background and shadow overrides on `<Card>`). Retired obsolete `input-bg-field` rule because `bg-field` is now the formal semantic background for inputs.
  - *Plugin Automation:* Upgraded `/semi-audit` to report physical class usage and semantic adoption rate. Upgraded `/semi-init` with an automated AST/regex codemod to map legacy Tailwind classes to semantic tokens, and replaced destructive blanket skips (`skip: { ...: ["src/app"] }`) with Ratchet baselines (`semi-lint-baseline.json`).
